# ADF

[공식 사이트·다운로드](https://adf-desktop.vercel.app) · [소스코드](https://github.com/Keilkim/ADF) · [최신 릴리즈](https://github.com/Keilkim/ADF/releases/tag/v0.3.28) · [기여 안내](CONTRIBUTING.md) · [코드 서명 현황](CODE_SIGNING.md)

**현재 배포 상태:** Windows용 0.3.28과 macOS용 0.3.27을 제공합니다. Mac용 0.3.28은 서명·공증을 마친 뒤 같은 릴리즈에 추가합니다. Mac용은 Developer ID 서명·Apple 공증을 완료했습니다. Windows용은 미서명이며 스마트 앱 컨트롤이나 SmartScreen이 실행을 차단하거나 경고할 수 있습니다. Windows Server 2022에서 설치·앱 실행·문서 처리·제거를 확인했으며, Windows 10/11의 실제 탐색기 통합과 입력 장치는 추가 확인이 필요합니다. 대응 소스와 검증 기록은 릴리즈에 있습니다.

ADF 자체 코드는 **AGPL-3.0-or-later**로 공개합니다. 웹사이트는 소개·다운로드·도움말을 담당하며, PDF 작업과 도장 보관은 데스크톱 앱의 로컬 처리로 유지합니다. 도장 이미지·이름·크기는 사용자 PC의 `stamps.sqlite3`에 저장됩니다.

Windows와 macOS에서 쓰는 로컬 PDF 편집기입니다. PDF를 읽고, 페이지를 정리하고, 병합·분리한 결과를 표준 `.pdf`로 저장합니다. 계정이나 서버 없이 동작하며 문서를 외부로 전송하지 않습니다.

**0.3.29**(배포 준비 중)에는 화면을 정리해 페이지를 더 크게 봅니다. 위쪽 문서 바와 맨 아래 상태 표시줄을 없애고, 보기 방식·첫 페이지 방향·전체 보기·페이지 맞춤·배율·전체 화면 버튼을 페이지 아래 바의 페이지 번호 양옆으로 옮겼습니다. 저장 상태는 메뉴 줄 오른쪽 끝에 표시하며, 저장하지 않은 변경이 있으면 빨간 **저장 안 됨**으로 바뀝니다. 안내 문구는 페이지 아래에 잠깐 떴다가 사라집니다(아래 **읽기**).

**0.3.28**에는 다섯 가지가 바뀝니다. 설치한 ADF가 인터넷에 연결되면 새 버전을 확인해 받아 두고 알려 주며, 한 번 누르면 업데이트한 뒤 보던 문서와 함께 다시 엽니다(아래 **업데이트**). 글자는 Adobe Acrobat처럼 글의 흐름대로 선택하고, 두 번 클릭은 단어·세 번 클릭은 문단을 선택합니다. 노트북 터치패드에서 두 손가락을 벌리거나 오므려 확대·축소하며, Mac 트랙패드의 핀치도 받습니다. 탐색기의 큰 아이콘 보기에서 PDF의 첫 페이지 썸네일이 보입니다. Windows 사용자 이름이 한글인 PC에서 **뜻으로 찾기**가 실패하던 문제를 고쳤습니다.

**0.3.27**에는 검색창의 **뜻으로 찾기**를 추가합니다. 글자가 달라도 뜻이 비슷한 문단을 가까운 순서로 찾으며, multilingual-e5-small 모델을 앱에 넣어 인터넷 없이 이 PC에서 처리합니다. 자세한 사용법은 아래 **검색** 항목을 참고하세요.

**0.3.26**은 보기 버튼의 선택·포커스 구분과 단일·마주보기의 정밀 휠·관성 처리를 수정합니다. 두 플랫폼의 앱 코드는 같으며, Windows 설치 파일도 동일한 수정 사항을 포함합니다. [변경 안내](docs/변경-보기버튼과-스크롤.md)를 참고하세요.

**0.3.25**에는 **Apple Silicon Mac(macOS 15 이상)용 앱**과 상단 도구 묶음 정리를 추가했습니다. 둘째 줄 도구를 **분할·페이지 추출 | 오른쪽·왼쪽 회전 | 페이지 번호·번호 삭제 | 이미지·텍스트 수정·펜·지우개 | 스냅·캡처·도장 보관함**으로 묶어 옅은 구분선으로 나눴습니다. 저용량 저장은 다른 이름 저장 오른쪽의 아이콘으로 옮겼고, 캡처도 한 번 더 누르면 해제됩니다. ADF가 넣은 페이지 번호는 다시 적용하면 바뀌고 **번호 삭제**로 지울 수 있습니다. [변경 및 검증 안내](docs/검증-0.3.25.md)를 참고하세요.

**0.3.24**에는 **펜·지우개 별도 토글 버튼**, 작은 모서리 화살표로 여는 간결한 옵션창, **굵기·크기 실시간 미리보기**, 누른 채 멈추는 **직선 보정**을 추가했습니다. 선택 글자는 파란색으로 강조하고 확정한 텍스트·캡처 영역은 움직이는 파선으로 표시합니다. [변경 및 검증 안내](docs/검증-0.3.24.md)를 참고하세요.

처음 실행하면 실제 버튼 위치를 짚는 **6단계 기능 투어**가 나타납니다. **건너뛰기** 또는 **시작하기**로 마치면 다음 실행부터 자동으로 나타나지 않으며, **도움말 → 기능 둘러보기**에서 다시 볼 수 있습니다. 텍스트·이미지·캡처를 복사하면 문서 아래쪽에 **복사되었습니다 · 클립보드 · Ctrl+V** 알림이 잠시 나타납니다. 전체화면에서도 표시하며 입력 초점을 옮기지 않습니다.

## 도장 보관함과 PDF 비교

도장 이미지를 보관해 반복해서 배치하고, PDF 두 버전의 변경 내용을 비교할 수 있습니다.

- **도장 보관함**: 상단 도구 줄 맨 오른쪽의 **도장 보관함**을 누릅니다. 오른쪽 패널의 **도장 등록하기**에서 파일을 불러오고 이름·너비(기본 20mm)를 저장합니다. 등록된 카드의 미리보기를 한 번 클릭하면 테두리 없는 짙은 회색 배경으로 선택되고 **스탬프 모드**가 됩니다. 도장 미리보기가 마우스를 따라가며 PDF를 클릭할 때마다 그 위치에 바로 찍힙니다. 별도 이미지 적용 단계는 없으며 Esc·우클릭·패널 닫기로 모드를 끝냅니다. Ctrl+Z로 한 번씩 취소할 수 있고 PDF는 마지막에 저장합니다. 카드에 마우스를 올리면 **이름 수정하기 / 삭제**가 나타납니다. 이름 수정하기는 파일·이름·너비를 수정하는 **도장 관리** 팝업을 엽니다. 등록을 취소하면 보관함에 추가되지 않습니다. 도장 삭제는 이미 찍은 PDF에 영향을 주지 않고, 마지막 삭제는 **도장 삭제 취소**로 복원합니다. 투명 배경·비율을 유지하며 페이지보다 큰 도장은 들어갈 크기로 줄입니다.
- **PDF 두 버전 비교**: 상단 **비교** 또는 **파일 → PDF 두 버전 비교…**에서 이전/수정 파일을 선택합니다. 선택한 파일의 **저장본**을 비교하므로 편집 중인 변경을 비교하려면 먼저 다른 이름으로 저장하세요. 페이지 내용을 기준으로 대응시킨 뒤 변경 목록·좌우 미리보기를 보여줍니다. **이전/다음 변경**(Alt+↑/↓), 페이지 쌍 선택, 양쪽 확대·스크롤 연동, 변경 표시 켜기/끄기를 지원합니다. 별도 프로세스에서 분석하므로 취소하거나 창을 닫을 수 있습니다.

보관함은 Qt의 사용자별 앱 데이터 폴더(`QStandardPaths.AppLocalDataLocation`) 아래 `stamps.sqlite3`에 저장합니다. 원본 이미지 파일을 옮겨도 보관한 이미지는 유지됩니다. 두 기능 모두 네트워크나 추가 모델 다운로드가 필요하지 않습니다.

같은 도장을 반복 배치할 때 `code=8: invalid key in dict`가 발생하던 PDF는 사용되지 않는 잘못된 객체가 실행 취소용 저장을 막는 경우였습니다. 작업 복사본과 저장용 복사본에서는 참조되지 않는 객체를 제외하되 사용 중인 객체 번호는 유지하도록 수정했습니다.

비교 범위는 추출 가능한 텍스트와 페이지에 보이는 이미지·도형·주석입니다. OCR, 메타데이터, 첨부파일, 디지털 서명 검증은 포함하지 않습니다. 스캔 화질이나 위치 차이도 화면 변경으로 표시될 수 있으며, 자동 페이지 대응은 문서를 크게 재배치한 경우 정확하지 않을 수 있습니다. 아주 미세한 색·픽셀 차이는 표시되지 않을 수 있습니다. 페이지 이동은 추가·삭제로 나타날 수 있습니다.

## 직원용 설치

직원이 설치하고 사용하는 데는 **설치 EXE 하나만 필요합니다.** 소스 ZIP 두 개는 설치하거나 압축을 풀 필요가 없습니다. 배포 담당자가 별도 소스 제공 자료로 공유합니다.

1. 사내 배포 폴더의 **`ADF-Setup-0.3.28.exe`**를 더블클릭합니다. 이전 버전이 있으면 같은 프로그램을 업데이트합니다.
2. **설치**를 누르면 현재 사용자 계정에 설치됩니다. Python 설치나 관리자 권한은 필요하지 않습니다. 바탕 화면 바로가기는 선택할 수 있습니다.
3. 시작 메뉴에서 **ADF**를 실행하면 빈 회색 작업 화면이 열립니다. PDF를 끌어 놓거나 **PDF 열기**를 누릅니다. 문서를 닫으면 다시 빈 작업 화면으로 돌아갑니다.

지원 대상은 Windows 10 1809 이상 / Windows 11의 Intel·AMD x64 PC입니다. 이번 탐색기 확장은 ARM64용이 아닙니다. 설치 위치는 `%LOCALAPPDATA%\Programs\ADF`입니다. 인터넷 연결은 개발 PC에서 빌드할 때 필요하며, 직원 PC의 설치와 문서 작업에는 필요하지 않습니다. 직원 PC에서는 업데이트 확인에만 씁니다.

## 업데이트

설치한 ADF는 인터넷에 연결되어 있으면 시작 20초 뒤 GitHub에서 최신 릴리즈를 확인하고, 열려 있는 동안 12시간마다 다시 확인합니다. 연결이 없으면 그대로 쓰고, 연결되는 즉시 다시 확인합니다. 새 버전이 있으면 설치 파일을 뒤에서 받아 릴리즈의 `SHA256SUMS`와 대조합니다. 준비되면 화면 오른쪽 아래에 Windows 알림을 띄우고, 메뉴 줄 오른쪽 끝, 저장 상태 옆에 **업데이트 설치** 버튼을 보여 줍니다. 알림은 Windows 알림 센터를 거치므로 다른 앱의 알림과 차례로 쌓이며 겹치지 않습니다.

알림이나 버튼을 한 번 누르면 다른 ADF 창을 닫고(각 창이 저장 여부를 묻습니다) 설치 파일을 진행 표시만 보이게 실행한 뒤 ADF와 보던 문서를 다시 엽니다. 설치 때 확인한 배포 조건은 업데이트에도 그대로 적용되며 알림에 적어 둡니다. 설치가 실패하거나 취소되어도 ADF를 다시 열고, 다음 실행에서 패치 대신 전체 설치 파일로 다시 시도합니다. 전체 설치 파일도 실패하면 다운로드 페이지를 안내합니다. ADF는 설치 프로그램이 풀어 실행한 설치 화면이 로그(`install-<버전>.log`)를 쓰기 시작할 때까지 최대 15초 기다린 뒤 종료합니다. 그 안에 로그가 생기지 않거나 설치 프로그램이 먼저 끝나면 Windows 보안 설정이 막은 것으로 보고, ADF 창과 보던 문서를 다시 열고 버튼으로 다운로드 페이지를 안내합니다.

- **패치**: 릴리즈마다 최근 세 버전에서 바뀐 파일만 담은 `ADF-Update-<이전>-to-<새>.exe`를 함께 올립니다. 이전 버전의 파일 목록 `ADF-Files-<버전>-Windows.json`과 비교해 만들며, 이름만 바뀐 외부 라이브러리 소스 ZIP은 설치 폴더의 파일을 해시 확인 후 복사합니다. 패치는 만들어진 버전에만 설치되고, 해당 패치가 없으면 전체 설치 파일을 받습니다.
- **데이터 요금제 연결**: 전체 설치 파일은 미리 받지 않고 버튼을 누를 때 받습니다. 받다가 끊기면 다음에 이어서 받습니다.
- **Mac**: 버튼을 누르면 새 DMG를 받고, 다 받으면 버튼이 **업데이트 설치**로 바뀝니다. 한 번 더 누르면 DMG를 열어 주며, ADF를 응용 프로그램 폴더로 끌어 놓아 바꿉니다.
- **스마트 앱 컨트롤**: Windows 11의 스마트 앱 컨트롤이 켜져 있으면(`HKLM\SYSTEM\CurrentControlSet\Control\CI\Policy`의 `VerifiedAndReputablePolicyState`=1) 서명되지 않은 설치 파일이 실행되지 않습니다. ADF는 아직 코드 서명이 없으므로 이런 PC에서는 업데이트를 받지 않고 버튼과 알림으로 다운로드 페이지를 안내합니다. 서명한 릴리즈부터는 `adf/updates.py`의 `smart_app_control_blocks_updates`만 거두면 됩니다.
- **받기 실패**: 받을 파일과 여유 공간 512MB가 디스크에 들어가지 않거나 쓰는 중 공간이 모자라면 받던 파일을 지우고 한 시간 뒤 다시 시도합니다. 받은 파일이 `SHA256SUMS`와 두 번 다르면 더 받지 않고 다운로드 페이지를 안내하며, 릴리즈의 체크섬이나 버전이 바뀌면 다시 받습니다. 최신 릴리즈가 받아 둔 버전보다 낮아지면(릴리즈를 내린 경우) 받아 둔 파일을 지웁니다.
- **끄기**: 앱의 **도움말 → 업데이트 자동 확인**을 해제합니다. IT 담당자는 `HKCU\Software\ADF\ADF\updates`에 문자열 값 `auto`=`false`를 배포해 끌 수 있습니다. 요청에는 앱 버전만 담기며 문서·파일 이름·도장은 보내지 않습니다. 회사 프록시 설정(PAC 포함)을 따릅니다.
- **대상**: 설치 프로그램으로 설치한 앱만 스스로 업데이트합니다. 소스 실행과 복사한 `dist/ADF` 폴더는 확인하지 않습니다. 자동 업데이트가 들어간 첫 버전은 한 번 직접 설치해야 합니다.

이 빌드는 코드 서명 인증서가 없는 설치 파일입니다. 사내 PC의 SmartScreen 또는 회사 보안 정책에 따라 실행 확인이나 IT 담당자의 배포 승인이 필요할 수 있습니다. 회사 배포용 서명 인증서가 있으면 배포 담당자가 설치 파일과 실행 파일에 서명할 수 있습니다. 보안 정책을 변경하는 기능은 설치 프로그램에 포함하지 않습니다.

## PDF 더블클릭으로 열기

설치하면 Windows의 PDF 연결 프로그램 후보에 **ADF**가 추가됩니다. **Windows 설정 → 앱 → 기본 앱**에서 ADF 또는 `.pdf`를 찾아 ADF를 선택하면 이후 PDF를 더블클릭해서 열 수 있습니다. PDF 우클릭 → **연결 프로그램 → 다른 앱 선택**에서도 지정할 수 있습니다. Windows 버전에 따라 버튼과 단계가 다르며 사용자가 직접 선택해야 합니다.

탐색기에서 PDF **한 개**를 우클릭하면 ADF 아이콘이 붙은 **ADF로 PDF 분할…**, PDF **두 개 이상**을 선택하고 우클릭하면 ADF 아이콘이 붙은 **ADF로 PDF 병합…**이 나타납니다. PDF 이외의 파일이 섞인 선택에는 병합·분할 메뉴를 표시하지 않습니다. Windows 11의 기본 간소화 메뉴에서는 **추가 옵션 표시** 안에 나타납니다.

탐색기의 **보기**를 **큰 아이콘** 이상으로 바꾸면 PDF 아이콘 대신 오른쪽 아래에 작은 ADF 로고가 붙은 **첫 페이지 썸네일**이 보입니다. Windows에 들어 있는 PDF 렌더러(`Windows.Data.Pdf`)로 그리므로 ADF가 PDF를 직접 해석하지 않으며, 탐색기의 격리된 썸네일 프로세스에서 실행됩니다. 다른 PDF 프로그램이 같은 자리에 썸네일 처리기를 등록해 두었으면 현재 사용자용이든 PC 전체용이든 그대로 두고, 제거할 때도 그 자리에 ADF 처리기가 남아 있을 때만 지웁니다. 암호가 걸린 PDF나 손상된 PDF는 아이콘으로 보입니다. 미서명 DLL이라 스마트 앱 컨트롤이 켜진 PC에서는 우클릭 메뉴처럼 차단될 수 있습니다.

메뉴를 누르면 선택한 파일이 들어 있는 **병합 또는 분할 창만 바로 열립니다**. 병합창에서 파일 순서를 바꾸고 필요한 페이지를 선택하거나, 분할창에서 범위를 정해 새 PDF로 저장하세요. **ADF로 열기**는 전체 편집기를 실행합니다. 탐색기의 기본 PDF 연결 프로그램은 ADF가 아니어도 됩니다.

## 작업 방법

이번 릴리즈는 **0.3.28**입니다. [릴리즈 안내](https://github.com/Keilkim/ADF/releases/tag/v0.3.28)에 변경 내용과 검증 범위를 정리했습니다.

상단 **펜**과 **지우개** 버튼 본체는 도구를 켜고 끄며, 각 버튼 오른쪽 아래 작은 대각선 화살표는 옵션을 엽니다. 펜슬·마카·브러쉬의 색·굵기는 선으로, 지우개 크기는 원으로 즉시 미리 보입니다. 미리보기의 배율은 오른쪽 아래에 표시합니다. 선을 그린 뒤 누른 채 약 0.6초 멈추면 시작점과 끝점을 잇는 직선으로 보정하며, 이후 같은 방향으로 길이를 조절합니다. 곡선·낙서·짧은 점은 유지합니다. 설정창 밖의 첫 입력은 창만 닫습니다.

텍스트는 Adobe Acrobat처럼 글의 흐름대로 선택합니다. 드래그하는 동안 첫 줄의 나머지·사이 줄 전체·끝 줄의 앞부분을 파란 강조로 보여 주고, 두 번 클릭은 단어, 세 번 클릭은 문단, Shift+클릭은 선택 늘리기입니다. 창 가장자리로 끌면 자동으로 스크롤합니다. Alt+드래그, 글이 없는 그림 위에서 시작한 드래그, 글자가 없는 스캔 페이지는 네모 영역으로 선택하며 가장자리에 움직이는 파선을 표시합니다. 다른 곳 클릭·Esc·도구 변경·문서 닫기로 선택과 강조가 함께 사라집니다. Windows에서 애니메이션을 끄면 파선은 정지합니다. **캡처** 도구나 **Ctrl+Shift+C**는 글·그림·그래프·표·필기를 함께 이미지로 복사하며 화면의 선택 표시를 포함하지 않습니다. 캡처도 펜·지우개처럼 한 번 더 누르면 해제됩니다. 표는 이미지 형태로 붙여넣으며 엑셀 셀 변환 기능은 포함하지 않습니다. 열기·저장·다른 이름으로 저장·저용량 저장·비교·OCR MD는 상단 첫 줄에 아이콘으로 표시하고, 마우스를 올리면 이름을 확인할 수 있습니다. 둘째 줄 도구는 **분할·페이지 추출 | 오른쪽·왼쪽 회전 | 페이지 번호·번호 삭제 | 이미지·텍스트 수정·펜·지우개 | 스냅·캡처·도장 보관함**을 옅은 구분선으로 묶고, 창이 좁으면 묶음 단위로 다음 줄에 이어집니다.

0.3.22에서는 상단 **펜 아이콘**에서 **펜슬·마카·브러쉬**, 검정·빨강·파랑·초록, 굵기 **0.2~12.0 pt(0.2 단위)**를 고릅니다. 기본값은 검정 펜슬, 1.2 pt입니다. 마카는 반투명하고 브러쉬는 선 끝과 필압에 따라 굵기가 달라집니다. 마우스나 Windows 스타일러스로 그리며 한 획씩 Ctrl+Z로 취소합니다. Esc·우클릭으로 펜 모드를 끝낸 뒤 **필기를 클릭**하면 **테두리 없이 크기 조절점 8개와 아래쪽 회전 핸들**이 나타납니다. 필기를 끌어 이동하고 조절점을 끌어 크기·회전을 바꿉니다. Shift를 누른 회전은 15도 단위이며 Delete로 선택한 필기를 지울 수 있습니다. 저장 후 다시 열어도 객체로 편집되고 인쇄됩니다. 전체화면에서 Esc는 전체화면을 해제합니다.

0.3.21에서는 문의 메뉴와 메일 초안 기능을 제거했습니다.

0.3.20에서는 OCR 내보내기의 이미지 저장 방식을 간단히 고릅니다. **MD 안에 이미지 포함(Base64)**이 기본이며 **이미지 폴더로 분리**도 지원합니다. MD·이미지 이름에 **날짜_문서이름_고유ID**를 붙이고 이미지에는 페이지·영역 번호도 덧붙입니다. 분리 방식은 상대경로로 연결하므로 결과 폴더 전체를 옮기면 연결이 유지됩니다. 내장 방식은 MD만 복사해도 이미지 데이터가 유지됩니다. 소스코드는 설치 파일에 포함된 자료를 앱 안에서 읽거나 원본 그대로 저장하며, 시작 메뉴의 사용안내·라이선스·소스코드도 앱에서 열립니다.

0.3.19에서는 도움말을 상단 메뉴에 모았습니다. 선택·손 도구는 **보기** 메뉴에서 전환합니다. 사용 안내·오픈소스 라이선스·소스코드는 각각 별도 창으로 열리며 서로의 검색 위치를 바꾸지 않습니다. 팝업과 전체 화면도 밝은 무채색으로 통일했습니다.

0.3.18에서는 설치에 **배포 조건 확인** 페이지를 추가했으며, 기본적으로 비어 있는 필수 확인란을 체크해야 다음 단계로 넘어갑니다. 문구의 무단 배포는 라이선스 조건을 위반한 배포를 뜻하며, 오픈소스 라이선스가 허용하는 사용·수정·재배포 권리는 유지됩니다.

0.3.17에서는 **OCR · MD**로 한글·영어 OCR, 문단·다단 읽는 순서, 표와 이미지·그래프·도형을 Markdown 묶음으로 내보냅니다. 모델을 설치 파일에 포함해 인터넷 없이 PC에서 처리합니다. 전체·현재·선택·직접 입력 페이지를 지원하며 저장 전 수정 내용도 포함합니다. 작업 중 **취소·Esc**를 누르면 중단하고 임시 결과를 정리합니다. 완료한 묶음만 새 폴더에 저장하며 기존 파일·폴더는 덮어쓰지 않습니다. **PDF 열기**도 별도 작업에서 진행하며 파일 읽기·구조 확인·페이지 확인·첫 화면 준비를 표시합니다. 읽은 바이트와 확인한 페이지로 실제 진행률을 계산하고, 총량을 알 수 없는 단계는 스피너로 표시합니다.

0.3.16에서는 **도움말 창**에서 사용안내를 검색하고 오픈소스 라이선스 원문을 읽을 수 있습니다. **F1**으로 사용안내를 엽니다. 설치 파일에 ADF와 외부 라이브러리의 해당 버전 소스 ZIP을 함께 넣으며, **도움말 → 소스코드**에서 해당 폴더를 엽니다. 시작 메뉴에서도 사용안내·라이선스·소스에 접근할 수 있습니다.

0.3.15에서는 보기 아이콘의 **전체 보기 오른쪽에 전체 화면 버튼**을 추가했습니다. **F11**로도 실행합니다. 전체화면에서는 PDF만 보이며 마우스를 **상단·왼쪽·하단 가장자리**로 가져가면 해당 도구가 슬라이드로 나타납니다. 마우스가 벗어나면 다시 숨겨집니다. **Esc·F11·문서 더블클릭**으로 해제하며 읽던 페이지, 이전 창 크기와 패널 너비를 유지합니다.

0.3.14에서는 오른쪽 문서 화면의 기본값을 **선택 도구**로 바꿨습니다. 텍스트 위에서는 커서가 **I 모양**으로 바뀌고 드래그로 글을 선택합니다. 이미지는 클릭해서 선택하며 **Ctrl+C**로 복사합니다. **Esc**나 빈 곳 클릭으로 선택을 해제하고, 문서를 끌어 움직이려면 **손 도구**를 고릅니다.

0.3.13에서는 비연속 페이지·현재 페이지 인쇄, 용지 맞춤·실제 크기·배율 지정, 자릿수에 맞는 페이지 번호 입력칸, 폭에 따라 열 수가 바뀌는 왼쪽 미리보기, 선택 페이지 추출을 제공합니다.

첫 실행에서는 기본 PDF 작업과 스냅 정렬·페이지 패널 접기·도장 보관함·두 버전 비교를 소개하는 시작 안내가 나타납니다. **시작하기**를 누르거나 창을 닫으면 다음 실행부터 자동으로 표시하지 않습니다. **도움말 → 기능 둘러보기**에서 버전과 주요 기능을 다시 확인하고, **자세한 사용 안내**로 전체 조작 방법을 열 수 있습니다.

0.3.12에는 **오브젝트 스냅**과 페이지 미리보기 접기·펼치기를 추가했습니다. 상단 **스냅** 또는 **보기 → 오브젝트 스냅**에서 켜고 끄며 설정을 기억합니다. 텍스트 상자 이동·크기 조절, 새 이미지 배치·이동·크기 조절, 도장 배치 시 같은 페이지의 텍스트·이미지·도형과 페이지 가장자리·중앙에 가까워지면 자동으로 맞춰집니다. 맞춰진 위치에는 분홍색 점선이 나타납니다. **Alt를 누르는 동안은 스냅이 잠시 해제**됩니다. 이미지 비율은 유지하며, 확대 배율과 관계없이 화면상 약 7px 이내에서 작동합니다. 정렬 안내선은 PDF에 저장하거나 인쇄하지 않습니다.

0.3.11 릴리즈에는 0.3.10의 PDF 저장 오류 수정에 도장 등록·관리 팝업, 기본 20mm 너비, 클릭 연속 배치, 회색 선택 카드·호버 수정/삭제, 페이지 위치 안정화를 함께 포함했습니다. PDF 두 버전 비교도 포함합니다. 소스 ZIP과 실행파일의 코드 일치 여부 및 설치 검증은 [0.3.11 검증 기록](docs/검증-0.3.11.md)을 참고하세요.

0.3.10에서는 PDF 내부의 사용하지 않는 손상 객체 때문에 클립보드 페이지 추가 등 편집 준비 중 `code=8: invalid key in dict`가 발생하던 문제를 수정했습니다. 실행 취소용 문서를 만들 때 사용하지 않는 객체를 정리하며, 참조되는 페이지 내용과 편집 기록은 유지합니다. 검증 범위와 결과는 [0.3.10 검증 기록](docs/검증-0.3.10.md)에 기록합니다.

왼쪽·오른쪽 시작 아이콘은 비활성 상태에서 그림 자체를 옅은 회색으로 표시합니다. 두 쪽 보기로 전환하면 원래 진하기로 돌아옵니다.

0.3.9에서는 보기 아이콘을 **한 쪽씩·연속 | 두 쪽씩·연속 | 전체 보기 | 시작 위치**로 나누고 얇은 회색 구분선을 넣었습니다. 왼쪽·오른쪽 시작 위치는 두 쪽 보기에서만 활성화됩니다. 저용량 저장 창에서는 자동 조절을 끄면 목표 용량을, 켜면 수동 해상도·JPEG 품질을 비활성화하며 입력칸과 항목 이름을 회색으로 표시합니다.

두 쪽 보기의 **왼쪽 시작**은 `[1 | 2] → [3 | 4]`, **오른쪽 시작**은 `[빈칸 | 1] → [2 | 3]`입니다. 끝에 짝이 없으면 반대 칸을 비워 두며, 실제 PDF 페이지를 추가하거나 순서를 바꾸지 않습니다. 첫 페이지의 기본 위치는 왼쪽입니다.

Windows 글꼴은 등록된 표시 이름과 별개로 파일 내부의 한글·영문 이름, 전체 이름과 PostScript 이름을 조회합니다. TTC·OTC 묶음에서는 해당 글꼴을 골라 편집과 페이지 번호 저장에 사용합니다. 글꼴 목록을 주기적으로 갱신하여 실행 중 설치된 파일도 다시 찾습니다. 가변 글꼴의 모든 이름별 인스턴스나 앱 전용 글꼴을 지원하는 것은 아닙니다.

앱과 탐색기 메뉴는 **배경 없는 파란 A** 아이콘을 사용합니다. [아이콘 원본과 제작 기록](assets/README.md)을 참고하세요.

왼쪽 페이지 미리보기는 하단 버튼 5개의 전체 폭에 맞춘 고정 크기입니다. 경계선을 넓히면 완전히 들어가는 열이 1열·2열·3열 등으로 늘고, 좁히면 줄어듭니다. Windows 화면 배율에 맞춰 PDF를 다시 그립니다. 경계 가운데의 돌출된 **‹ 버튼**으로 패널을 접을 수 있습니다. 접으면 왼쪽에 12px의 얇은 띠와 **› 버튼**이 남으며, 다시 누르면 접기 전 너비로 펼쳐집니다. 현재 페이지와 미리보기 스크롤 위치를 유지하며, Tab으로 버튼을 선택한 뒤 Space로도 조작합니다. 크게 확대하면 보이는 부분만 고해상도로 렌더링하여 메모리 사용을 제한합니다.

이미 수정한 문단을 다시 선택하면 적용했던 내장 글꼴을 재사용합니다. 대체 글꼴 선택 창의 **이 문서의 같은 글꼴에 이 선택 적용**을 체크하면 같은 원본 글꼴에 대한 선택을 현재 문서에서 기억합니다. 기본은 체크 해제이며, 다른 글꼴과 다른 문서는 따로 확인합니다. 기억한 글꼴에 새 글자가 없으면 다시 확인합니다.

- **검색**: **Ctrl+F**로 검색창을 엽니다. 기본은 입력한 글자를 그대로 찾고, **뜻으로**를 켜면 글자가 달라도 뜻이 비슷한 문단을 가까운 순서로 10곳까지 강조합니다(예: "계약 해지 조건"으로 "해약하려면 30일 전에 알려야 합니다" 찾기). 문서를 처음 뜻으로 찾을 때 글을 색인하며, 모델(multilingual-e5-small)을 앱에 넣어 인터넷 없이 이 PC에서 처리합니다. 글자가 없는 스캔 페이지는 찾지 못하고, 수정한 뒤에는 다음 검색에서 다시 색인합니다. 이 모델 때문에 Mac DMG는 약 0.31GB(실측 1.01→1.32GB), 설치한 앱은 약 0.5GB 커집니다.
- **인쇄**: 전체·현재 페이지·선택한 페이지·직접 입력 중 대상을 고릅니다. `1,3,5-8`처럼 번호와 범위를 함께 입력할 수 있습니다. 용지에 맞춤·큰 페이지만 축소·실제 크기·배율 지정을 선택한 뒤 **프린터 선택…**에서 프린터, 용지, 방향과 매수를 정합니다. 선택한 용지의 인쇄 가능 영역에 비율을 유지해 배치합니다.
- **페이지 추출**: 왼쪽에서 페이지를 고른 뒤 상단 **페이지 추출**, 우클릭 또는 파일 메뉴의 **선택 페이지 추출…**을 누릅니다. 범위를 확인하고 파일명·저장 위치를 골라 새 PDF로 저장합니다. 저장 전 수정 내용도 포함되며 원본과 현재 작업은 유지됩니다.
- **읽기**: 보기 옵션은 모두 페이지 아래 바에 있습니다. 왼쪽부터 한 쪽씩·한 쪽 연속, 두 쪽씩·두 쪽 연속과 첫 페이지를 왼쪽·오른쪽에 놓는 펼침 아이콘(두 쪽 보기에서만), 이전·페이지 번호·다음, 전체 보기(격자)·페이지 맞춤·확대 배율, 전체 화면 순서입니다. 문서 이름은 창 제목에, 저장 상태는 메뉴 줄 오른쪽 끝에 표시하며 저장하지 않은 변경이 있으면 빨간 **저장 안 됨**으로 바뀝니다. 상태 표시줄은 없고 안내 문구는 페이지 아래 바 위에 잠깐 떴다 사라집니다. 한 쪽씩·두 쪽씩 보기에서 휠로 끝을 넘으면 이전·다음 페이지 묶음으로 이동합니다. 확대 상태에서는 먼저 현재 페이지 안에서 스크롤합니다.
- **페이지 정리**: 왼쪽 썸네일에서 Ctrl / Shift로 여러 페이지를 고른 다음 이동·좌우 회전·삭제·다른 PDF 페이지 교체를 합니다.
- **페이지 추가 / 분할**: 왼쪽 아래 **+**에서 빈 페이지, 클립보드 이미지·파일, PDF·PNG·JPG 파일을 추가합니다. 썸네일 사이에 마우스를 올리면 같은 **+**가 나타납니다. 한 파일은 바로 넣고, 여러 파일은 순서를 정한 뒤 선택한 위치에 추가합니다. 파일이나 페이지를 끄는 동안에는 추가 버튼 대신 삽입 위치 선을 표시합니다. 별도 병합 파일은 탐색기 우클릭이나 파일 메뉴의 **PDF 병합**을 사용합니다.
- **편집 도구**: 텍스트 수정 모드에서 글자를 클릭하면 줄바꿈으로 이어지는 같은 문단을 함께 선택하고, 페이지 위에서 바로 입력합니다. 선택했을 때만 상단에 글꼴·크기·색 도구가 나타납니다. 선택 상자의 테두리를 끌어 이동하고 오른쪽 아래 손잡이로 크기를 바꿉니다.
- **원본 글꼴 유지**: PDF 안에 포함된 사용 가능한 글꼴을 먼저 재사용합니다. PC에 설치할 필요가 없으며, 화면 편집과 저장에 같은 글꼴 데이터를 씁니다. 새 글자가 내장 글꼴에 없으면 같은 PC 글꼴을 확인하고, 그것도 없을 때만 **대체 글꼴로 편집 / 편집 취소**를 묻습니다. 취소하면 현재 문단을 유지하며 앞서 끝낸 다른 수정은 남습니다.
- **페이지 번호**: 미리보기 가장자리의 위치 아이콘을 누릅니다. **맞쪽 번호 · 좌우 대칭**을 켜면 왼쪽·오른쪽 페이지의 위치를 대칭으로 적용하며, 본문 뷰어의 첫 페이지 시작 위치와 빈칸 배치를 따릅니다. 좌우 여백은 번호가 붙는 쪽 가장자리 기준입니다. 적용 페이지를 비워 두면 전체이며, **앞에 0 넣기**는 마지막 번호에 맞춰 자동으로 자릿수를 정합니다(예: 001…120). 번호 앞뒤는 없음·p.1·1p 중 고릅니다. 글꼴·크기·색을 한 줄에서 조절하고 색상 코드를 직접 입력할 수 있습니다. ADF가 넣은 번호가 있는 페이지에 다시 적용하면 그 번호를 새 설정으로 바꾸고, 상단 **번호 삭제**는 ADF가 넣은 번호만 지웁니다(Ctrl+Z로 복원). 이전 버전이나 다른 프로그램에서 넣은 번호와 직접 고친 번호는 건드리지 않습니다. 분할·추출·병합으로 만든 새 PDF의 번호도 지우지 않습니다.
- **저장**: 상단 **저장** 또는 **Ctrl+S**로 현재 파일에 변경을 기록합니다. **다른 이름 저장**은 저장 버튼 오른쪽에 있으며 **Ctrl+Shift+S**로 새 파일을 만듭니다. 경로가 없는 새 문서는 저장 위치를 먼저 고릅니다. 텍스트·필기·이미지·페이지 작업은 저장 전까지 디스크 파일을 바꾸지 않습니다.

`Ctrl+O` 열기, `Ctrl+S` 저장, `Ctrl+Z` 실행 취소, `Ctrl+Shift+Z` 다시 실행, `Ctrl+휠` 또는 터치패드 핀치 확대/축소, `PgUp / PgDn` 페이지 이동, `F11` 전체 화면을 사용합니다. 암호 PDF는 열람 암호를 입력합니다. 소유자가 편집을 제한한 PDF는 허용 권한 또는 소유자 암호가 필요합니다.

이미지는 **이미지 적용**을 누르기 전에 끌어서 위치를 정하고 오른쪽 아래 모서리로 크기를 조절합니다. 적용한 뒤 다시 배치하려면 실행을 취소하고 새로 삽입하세요. 기존 이미지 선택 모드는 삭제를 지원하며 이미 저장된 이미지의 이동·크기 변경은 지원하지 않습니다.

페이지 위에서 **Enter**는 줄바꿈입니다. 빈 곳이나 다른 문단을 클릭하면 수정 내용이 현재 작업에 반영되며 **완료**, **Ctrl+Enter**, 최종 저장으로도 반영됩니다. 입력한 내용이 길어지면 문단 상자가 페이지 안에서 아래로 늘어납니다. PDF의 배치 정보를 바탕으로 문단을 묶으므로 떨어진 열이나 표의 셀은 따로 선택합니다. 모든 PDF에서 의미상 문장 경계를 정확하게 알아내는 것은 아니며, 문서 전체의 글과 페이지를 자동으로 밀어내는 재배치는 지원하지 않습니다. 텍스트 수정 시 기존 이미지와 선·도형은 유지합니다. 스캔 문서의 글자는 **OCR · MD**로 별도 내보낼 수 있으며, 원본 PDF에 텍스트 레이어를 추가하는 기능은 아닙니다.

전체 페이지를 이미지로 변환하는 압축 방식에서는 텍스트 검색·복사, 링크, 양식 등이 유지되지 않습니다. **이미지만 최적화**는 텍스트를 유지합니다. 목표 용량은 문서 내용에 따라 달성하지 못할 수 있으며 실제 결과를 확인하고 저장하세요. 원본 파일은 보관하는 것이 좋습니다.

## 사내 배포 담당자

직원에게는 **`ADF-Setup-0.3.28.exe` 하나를 전달하면 됩니다.** Mac 사용자에게는 Mac용 0.3.28이 추가되기 전까지 `ADF-0.3.27-macOS.dmg`를 전달합니다. 설치 파일 안에 실행에 필요한 구성 요소, 사용안내, 라이선스 원문, 해당 버전의 ADF 및 외부 라이브러리 소스 ZIP과 OCR 모델 5개와 뜻 검색 모델이 포함됩니다. 소스는 설치 후에도 인터넷 없이 복사할 수 있습니다. `release`의 별도 소스 ZIP과 안내 HTML은 설치 전 열람과 배포 담당자의 보관을 위한 동일 내용의 사본입니다.

| 파일 | 용도 |
| --- | --- |
| `ADF-Setup-0.3.28.exe` | 사용안내·라이선스·소스까지 포함한 Windows 설치·업데이트 파일 |
| `ADF-Source-0.3.28.zip` | ADF와 탐색기 확장 소스, 테스트, 빌드 방법, 라이선스 |

배포 담당자가 아래 배포 조건을 확인한 뒤 명시적으로 확인하는 무인 설치 명령은 `ADF-Setup-0.3.28.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /ADFACKNOTICE=0.3.28`입니다. 해당 명령도 실행한 사용자에게 설치됩니다. 관리자 계정에서 실행하면 그 관리자에게 설치되므로 일반 사용자 배포는 사용자 문맥에서 실행하세요. 제거는 Windows 설정 → 앱 → 설치된 앱 → ADF에서 합니다. 설치·제거는 다른 PDF 프로그램의 기본 연결을 강제로 바꾸지 않습니다. 개인 PDF 파일은 제거 대상이 아닙니다. 제거하면 자동 업데이트가 받아 둔 설치 파일과 로그(`%LOCALAPPDATA%\ADF\ADF\updates`)도 지웁니다. 도장 보관함과 앱 설정은 남깁니다.

업데이트는 0.1.0의 기존 정적 분리 메뉴를 정리하고 새 탐색기 확장을 등록합니다. 확장 DLL에 버전을 붙여 교체하며 탐색기 프로세스를 강제 종료하지 않습니다. 설치가 끝나면 이전 버전의 소스 ZIP(버전마다 약 0.7GB)과 탐색기가 쓰지 않는 이전 DLL을 지웁니다. 탐색기가 아직 쓰는 DLL은 다음 업데이트에서 지웁니다. 관리자 권한 없는 제거 중 탐색기가 DLL을 사용하고 있으면 메뉴 등록은 제거되어도 DLL 파일이 남을 수 있습니다. 이 경우 로그아웃한 뒤 남은 설치 파일을 정리할 수 있습니다. 같은 버전 재설치는 동일 버전의 DLL을 덮어쓰지 않습니다. 기존 0.1.0 배포 파일은 보존합니다.

`dist/ADF`는 Python과 Qt를 함께 담은 실행 폴더입니다. 설치 없이 사용하려면 이 폴더 **전체**를 복사하고 `ADF.exe`를 실행할 수 있습니다. 실행 파일만 따로 복사하면 동작하지 않습니다.

PyMuPDF / MuPDF의 AGPL, Qt / PySide의 LGPL 및 개별 오픈소스 조건이 적용됩니다. 새로 작성한 ADF 코드는 AGPL-3.0-or-later로 제공합니다. 앱의 도움말과 설치 폴더의 `_internal/LICENSES`에서 원문 고지를 볼 수 있으며, 자세한 소스 제공 및 라이브러리 교체 방법은 [라이선스 안내](LICENSES/README.md)를 참고하세요.

## 개발 및 Windows 설치 파일 빌드

빌드 PC에 64비트 Python 3.12가 있어야 합니다. 프로젝트 경로의 PowerShell에서 실행합니다.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe main.py
```

설치 파일 및 소스 묶음 생성:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build-windows.ps1
```

이 명령의 `ExecutionPolicy`는 해당 빌드 프로세스에만 적용됩니다. 버전을 고정한 의존성과 아이콘을 준비하고 `scripts/build-shell.ps1`로 C++ 탐색기 확장을 빌드·검증한 뒤 PyInstaller로 실행 폴더를 만듭니다. LLVM-MinGW 도구 모음은 지정 버전을 `.tools`로 받아 SHA-256을 확인합니다. 직원 PC에는 C++ 빌드 도구가 필요하지 않습니다. `ADFShell-0.3.26.dll`은 `ADF.exe` 바로 옆에 배치합니다.

Inno Setup 6.7.3은 공식 GitHub 배포에서 다운로드하며 SHA-256과 디지털 서명을 검사합니다. 컴파일러는 `.tools`에 portable 모드로 준비하므로 시스템에 별도로 설치되지 않습니다. 다운로드된 소스와 도구는 후속 빌드에서 재사용됩니다. 이 절차는 재빌드 가능한 패키징 절차이며 바이트 단위의 동일 바이너리를 보장하지 않습니다.

이미 의존성이 준비되었으면 `-SkipDependencies`, 실행 폴더만 필요하면 `-SkipInstaller`를 사용할 수 있습니다. 의존성 버전과 외부 소스 해시는 `LICENSES/build-manifest.json`에 기록됩니다. 라이브러리 버전을 변경하면 소스와 고지도 함께 갱신하세요. `prepare-ocr.py`로 모델의 배포처 SHA-256을 검증하고 `collect-licenses.py` 실행 후 `package-sources.py`로 소스를 묶고 PyInstaller가 `_internal/SOURCES`에 포함합니다. `package-release.py`는 실행 폴더에 포함된 소스와 현재 작업 파일이 일치하는지 검사한 뒤 같은 ZIP을 배포 폴더로 복사합니다.

설치 파일을 만든 뒤 `make-update-patches.py`가 실행 폴더의 파일 목록 `release/ADF-Files-<버전>-Windows.json`을 쓰고, 최근 세 릴리즈의 파일 목록과 비교해 업데이트 패치를 만듭니다. 바뀐 파일이 전체의 40%를 넘거나 이전 목록을 받을 수 없으면 패치 없이 전체 설치 파일만 배포합니다. `GH_TOKEN`을 설정하면 GitHub API 호출 한도를 피할 수 있습니다. 외부 라이브러리 소스 ZIP은 항목 시각을 고정하고 안의 `build-manifest.json`에서 ADF 자체 버전을 빼서, 외부 소스가 같으면 버전이 달라도 같은 바이트가 되도록 만듭니다. 패치를 작게 유지하려면 Python과 의존성 버전을 고정한 채로 빌드하세요.

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
.\dist\ADF\ADF.exe --smoke-test "$env:TEMP\adf-smoke.json"
powershell -ExecutionPolicy Bypass -File scripts\test-installer.ps1
powershell -ExecutionPolicy Bypass -File scripts\test-update-patch.ps1
```

`test-update-patch.ps1`은 만든 패치마다 해당 이전 버전의 공개 설치 파일을 받아 해시를 확인하고, 같은 격리 방식으로 설치한 뒤 앱이 쓰는 인수 그대로 패치를 실행합니다. 결과 파일이 새 빌드와 하나하나 같은지, 이전 버전 파일이 남지 않았는지, ADF가 열려 있던 문서와 함께 다시 시작되는지, 다른 버전에는 패치가 설치되지 않는지 확인한 뒤 제거합니다.

마지막 명령은 실제 배포 설치 파일에 `/ADFISOLATEDTEST=<임의 토큰>`을 전달해 임시 폴더와 전용 HKCU 하위 키, 별도 시작 메뉴 그룹에 설치합니다. 기존 ADF의 파일 해시·레지스트리·바로가기와 `.pdf` 기본 연결이 유지되는지 비교하고 테스트 설치만 제거합니다. 제거 때 지우는 업데이트 폴더는 실제 사용자의 폴더라 격리 설치에서는 제거 기록에 넣지 않습니다. 검증은 제거 기록(`unins000.dat`)에 이 폴더가 없고 원래 있던 폴더가 제거 후에도 남는지만 확인하며, 실제 삭제는 받아 둔 업데이트를 지우게 되므로 시험하지 않습니다. 네이티브 COM 선택 메뉴와 설치된 프로그램의 독립 병합·분할 창, 내보내기를 검증합니다. 일반 배포에는 이 검증 전용 옵션을 쓰지 않습니다. 버전별 결과는 `release`, 상세 로그는 `.tools/verification`에 남습니다.

이 빌드 PC에서는 0.3.3 검증 당시 Windows Application Control이 새로 컴파일한 `shell-tests.exe`의 실행을 차단했습니다. 설치 검증의 `-SkipNativeHarness`는 네이티브 선택 메뉴 검증을 생략했다고 결과 JSON에 기록하는 옵션이며, 보안 정책이나 실행 차단을 해제하지 않습니다.

0.3.3의 `ADF.exe`와 설치 내부 로더도 같은 서명 정책에 차단됐습니다. 이 제한이 해소되지 않아 **0.3.9 배포 파일의 실행·설치 검증은 수행하지 않았습니다.** 소스 실행의 텍스트 입력·저장 및 페이지 편집 테스트는 통과했습니다. 회사에서 허용하는 코드 서명·배포 승인 절차를 거친 환경에서 배포 바이너리를 검증해야 합니다. 기존 설치와 기본 PDF 연결은 변경하지 않았습니다.

CLI: `ADF.exe "문서.pdf"`는 전체 편집기, `ADF.exe --split "문서.pdf"`는 독립 분할창, `ADF.exe --merge "A.pdf" "B.pdf"`는 독립 병합창을 엽니다. 탐색기 확장은 선택한 모든 경로를 일회용 `--shell-request` JSON으로 전달합니다. JSON은 사용자별 요청 폴더 안에서 확인 후 소비하므로 명령행 길이 제한이나 파일별 프로세스 호출을 통한 수집에 의존하지 않습니다.

## macOS

Mac에서 이어 개발하는 방법과 검증 기록은 [Mac 개발 인수인계](docs/macos-development.md)에 정리했습니다.

Mac용 앱은 **Apple Silicon Mac의 macOS 15 이상**을 지원합니다. PySide6 6.11.2의 Apple Silicon용 모듈이 macOS 15 기준으로 빌드되어 있고, OCR에 쓰는 ONNX Runtime 1.29.0은 Intel Mac용 배포 파일이 없어 Intel Mac은 지원하지 않습니다. `ADF-<버전>-macOS.dmg`를 열고 ADF를 응용 프로그램 폴더로 끌어 놓으면 설치됩니다. 사용안내·라이선스·대응 소스·OCR 모델이 앱에 포함되어 인터넷 없이 사용합니다. Windows 탐색기의 병합·분할 메뉴는 Mac에 없으며, Finder에서 PDF를 ADF로 열거나 앱 창에 끌어 놓습니다.

빌드는 Mac에서 `bash scripts/build-macos.sh`로 합니다. `python3.12`가 없으면 `PYTHON` 환경 변수로 Python 3.12를 지정합니다. `ADF_CODESIGN_IDENTITY`에 Developer ID Application 인증서를, `ADF_NOTARY_PROFILE`에 `xcrun notarytool store-credentials`로 저장한 프로필을 지정하면 앱과 DMG를 서명·공증합니다. 지정하지 않으면 빌드한 Mac에서만 확인할 수 있는 ad-hoc 서명 빌드가 되며, 다른 Mac에서는 Gatekeeper가 실행을 막습니다. Windows에서 Mac 실행 파일을 크로스 컴파일하지 않습니다.

PyPI의 macOS용 OpenCV wheel은 FFmpeg와 x264·x265 등 GPL 영상 코덱을 함께 담고 있습니다. ADF는 영상을 쓰지 않으므로 빌드 스크립트가 `scripts/build-opencv-macos.py`로 같은 버전의 OpenCV 원본 소스를 영상 입출력 없이 컴파일해 설치합니다. Mac용 고지는 macOS wheel에서 `build/licenses`로 따로 생성하며, 저장소의 `LICENSES`는 Windows 빌드 기준으로 유지합니다.
