XDF 사용안내

처음부터, 차근차근.

설치한 뒤에는 계정이나 인터넷 연결 없이 문서 작업을 시작할 수 있습니다.

Windows 0.3.37부터 XDF 이름과 새 도구 배치를 사용합니다. macOS 0.3.30은 기존 ADF입니다.
Windows용 0.3.44과 macOS용 0.3.30을 제공합니다. macOS용은 Apple 공증을 받았고, Windows용은 미서명이라 스마트 앱 컨트롤이나 SmartScreen에 의해 실행이 차단되거나 경고가 표시될 수 있습니다. 현재 배포 상태를 확인하세요.

1. 설치하고 PDF 열기

macOS용은 Apple Silicon Mac(M1 이후)의 macOS 15 이상에서 쓸 수 있습니다.

  1. 다운로드 페이지에서 macOS용 DMG를 받습니다. 소스 ZIP은 앱을 쓰는 데 따로 필요하지 않습니다.
  2. DMG를 열고 XDF를 응용 프로그램 폴더로 끌어 놓습니다. Python과 OCR 모델은 앱에 포함돼 있습니다.
  3. 응용 프로그램 폴더에서 XDF를 열고 PDF를 끌어 놓거나 열기 버튼을 누릅니다.

Windows에서는 홈페이지의 Windows용 EXE를 내려받아 실행하고 설치 안내를 따릅니다. 설치한 뒤 시작 메뉴에서 XDF를 엽니다. Python과 OCR 모델은 설치 파일에 포함돼 있습니다. 현재 파일은 미서명이며, 실행이 차단되는 환경에는 추후 서명본을 제공합니다.

첫 실행에는 6단계 기능 투어가 나타납니다. 건너뛸 수 있으며, 도움말 → 기능 둘러보기에서 언제든 다시 볼 수 있습니다.

2. 도장을 내 PC에 보관하기

  1. 도장 보관함 → 도장 등록하기에서 PNG 또는 JPG 이미지를 고릅니다.
  2. 이름과 너비를 정하고 저장합니다. 기본 너비는 20 mm입니다.
  3. 보관함에서 도장을 선택하고 PDF의 원하는 위치를 클릭합니다. 연속으로 찍을 수 있습니다.
  4. Esc 또는 오른쪽 클릭으로 도장 배치를 끝내고 PDF를 저장합니다. Ctrl+Z로 배치를 취소할 수 있습니다.

도장의 이미지·이름·크기는 사용자별 로컬 앱 데이터 폴더에 보관됩니다. 등록 후 원본 이미지 파일을 옮겨도 보관함에 남습니다. 보관함에서 도장을 삭제해도 이미 저장한 PDF의 도장은 없어지지 않습니다. 보관·백업 안내

3. 필기하고 지우기

펜 또는 지우개 버튼을 눌러 도구를 켜고 끕니다. 버튼 오른쪽 아래 작은 화살표로 옵션을 열어 굵기·색상·크기를 미리 확인하세요. 선을 그린 뒤 누른 채 약 0.6초 멈추면 거의 곧은 선이 직선으로 보정됩니다.

도구함의 버튼·작은 화살표·손잡이 또는 편집 중인 문서를 우클릭하면 Esc와 같이 열린 옵션창을 닫거나 현재 도구를 해제합니다.

4. 도형 편집과 복사

도형 선택의 작은 화살표는 도형을 선택하기 전에도 속성창을 엽니다. 문서에서 벡터 도형을 클릭하면 창을 유지하면서 채움색·외곽선색·선 두께를 바꿀 수 있습니다. 선택한 도형이 없으면 새 도형의 기본값을 정합니다.

속성창에서 사각형·타원·선을 골라 페이지에서 끌어 그립니다. 처음에는 채움 없이 검정 0.5 pt 외곽선을 사용하며, Shift를 누르면 정사각형·원·45도 단위 선을 그립니다. 그리는 도중 Esc는 취소입니다.

도형·이미지는 조절점 8개로 크기를 바꾸고 Shift로 비율을 유지합니다. 벡터 도형을 더블클릭하면 앵커와 베지에 핸들을 끌어 모양을 수정합니다. 클리핑 그룹은 마스크와 내용을 함께 편집하고 더블클릭으로 안쪽 객체를 선택합니다. Delete는 선택한 도형을 삭제하며 Ctrl+Z로 되돌릴 수 있습니다. 도구함과 속성창은 페이지를 스크롤해도 제자리에 있습니다.

글자를 드래그하면 주홍색으로 선택됩니다. Ctrl+C로 텍스트를 복사합니다. 캡처 또는 Ctrl+Shift+C로 선택한 영역을 이미지로 복사하면 표·그래프·그림도 함께 담깁니다. 복사 알림이 나타나면 붙여넣을 앱에서 Ctrl+V를 누르세요. 표는 이미지로 복사되며 편집 가능한 셀로 변환되는 것은 아닙니다.

0.3.44부터 PDF의 빈 공백이 달러 기호로 잘못 추출되는 경우 글 수정 화면에서 자동으로 복원합니다. 공백이 빠진 PDF 부분 글꼴에도 빈 글리프와 간격을 보완하며, 실제 통화 기호는 유지합니다.

5. 페이지 정리와 문서 비교

병합·분할·페이지 추출로 문서를 정리하고 회전·페이지 번호를 적용할 수 있습니다. 비교에서 저장된 PDF 두 개를 선택하면 변경 목록과 나란한 미리보기가 열립니다. 현재 편집 내용을 비교하려면 먼저 저장하세요.

6. OCR로 Markdown 내보내기

OCR MD에서 대상 페이지를 정하고 내보냅니다. 한국어·영어 인식과 문단 배치를 처리하며 표·그림을 함께 담습니다. 이미지는 Markdown 안에 포함하거나 별도 폴더로 저장할 수 있습니다. OCR은 PC에서 처리되며 결과는 원본과 대조해 확인하세요.

7. PDF를 한글(HWPX)로 변환하기

  1. 상단 한글 변환 버튼 또는 파일 → 한글(HWPX)로 변환에서 전체·현재·선택·직접 입력 페이지를 고릅니다.
  2. 로컬 추출 또는 연결이 준비된 Gemini AI를 선택합니다. 공개 설치 파일에는 개인 API 키가 포함되지 않습니다.
  3. Gemini AI를 사용할 때는 선택한 페이지의 이미지·텍스트 전송 항목을 직접 켭니다. 기본 모델은 Gemini 3.5 Flash-Lite입니다.
  4. 새 HWPX 파일로 저장합니다. 문단·표는 편집할 수 있으며 그림·도형·수식은 이미지로 담습니다.

저장 전 PDF 수정 내용도 포함합니다. 한 번에 최대 100쪽을 변환하며 작업 중 취소할 수 있습니다. 기존 결과는 덮어쓰지 않습니다. 글꼴은 맑은 고딕으로 대체하고, 원본의 줄바꿈·여백·다단 배치는 그대로 재현되지 않을 수 있으므로 한글에서 원본과 대조하세요.

8. 업데이트 알림

0.3.42에서는 여러 XDF 창을 열어도 업데이트 알림을 한 곳에만 표시합니다. 업데이트 버튼을 누르면 설치용 창을 한 번만 열고, 설치를 시작하는 동안 같은 알림과 창을 반복해서 띄우지 않습니다. 설치가 진행되지 않으면 약 2분 뒤 알림이 다시 나타납니다.

Windows에서는 로그인할 때 시작한 백그라운드 실행이 XDF 창을 열기 전에도 새 버전을 확인하고 트레이가 있는 모니터의 오른쪽 아래에 알립니다. 이미 안내한 버전은 XDF를 켰을 때 다시 묻지 않습니다. 알림의 업데이트나 앱 메뉴 줄의 업데이트 설치를 누르면 설치할 수 있습니다. 나중에 다시 보기를 누르면 다음 날 아침 9시에 다시 알려 줍니다.

알림은 밝은 불투명 배경과 XDF 주홍색으로 표시합니다. 트레이 아이콘이 숨겨져 있어도 작업 표시줄의 모니터를 찾고, 모니터 구성이 바뀌면 위치를 갱신합니다. 설치·업데이트 뒤에는 바탕화면 PDF 미리보기도 새로 고칩니다. 바탕화면 아이콘 크기와 배치는 유지합니다.

자세한 안내와 문제 제보

앱에서 F1을 누르면 전체 사용안내가 열립니다. 전체 안내 소스와 GitHub 문제 제보도 이용할 수 있습니다. 공개 이슈에는 실제 도장이나 개인정보가 있는 문서를 첨부하지 말고, 가상의 예시로 재현해 주세요.
