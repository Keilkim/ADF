ADF 사용안내

처음부터, 차근차근.

설치한 뒤에는 계정이나 인터넷 연결 없이 문서 작업을 시작할 수 있습니다.

Windows용 0.3.29와 macOS용 0.3.27을 제공합니다. macOS용은 Apple 공증을 받았고, Windows용은 미서명이라 스마트 앱 컨트롤이나 SmartScreen에 의해 실행이 차단되거나 경고가 표시될 수 있습니다. 현재 배포 상태를 확인하세요.

1. 설치하고 PDF 열기

macOS용은 Apple Silicon Mac(M1 이후)의 macOS 15 이상에서 쓸 수 있습니다.

  1. 다운로드 페이지에서 macOS용 DMG를 받습니다. 소스 ZIP은 앱을 쓰는 데 따로 필요하지 않습니다.
  2. DMG를 열고 ADF를 응용 프로그램 폴더로 끌어 놓습니다. Python과 OCR 모델은 앱에 포함돼 있습니다.
  3. 응용 프로그램 폴더에서 ADF를 열고 PDF를 끌어 놓거나 열기 버튼을 누릅니다.

Windows에서는 홈페이지의 Windows용 EXE를 내려받아 실행하고 설치 안내를 따릅니다. 설치한 뒤 시작 메뉴에서 ADF를 엽니다. Python과 OCR 모델은 설치 파일에 포함돼 있습니다. 현재 파일은 미서명이며, 실행이 차단되는 환경에는 추후 서명본을 제공합니다.

첫 실행에는 6단계 기능 투어가 나타납니다. 건너뛸 수 있으며, 도움말 → 기능 둘러보기에서 언제든 다시 볼 수 있습니다.

2. 도장을 내 PC에 보관하기

  1. 도장 보관함 → 도장 등록하기에서 PNG 또는 JPG 이미지를 고릅니다.
  2. 이름과 너비를 정하고 저장합니다. 기본 너비는 20 mm입니다.
  3. 보관함에서 도장을 선택하고 PDF의 원하는 위치를 클릭합니다. 연속으로 찍을 수 있습니다.
  4. Esc 또는 오른쪽 클릭으로 도장 배치를 끝내고 PDF를 저장합니다. Ctrl+Z로 배치를 취소할 수 있습니다.

도장의 이미지·이름·크기는 사용자별 로컬 앱 데이터 폴더에 보관됩니다. 등록 후 원본 이미지 파일을 옮겨도 보관함에 남습니다. 보관함에서 도장을 삭제해도 이미 저장한 PDF의 도장은 없어지지 않습니다. 보관·백업 안내

3. 필기하고 지우기

펜 또는 지우개 버튼을 눌러 도구를 켜고 끕니다. 버튼 오른쪽 아래 작은 화살표로 옵션을 열어 굵기·색상·크기를 미리 확인하세요. 선을 그린 뒤 누른 채 약 0.6초 멈추면 거의 곧은 선이 직선으로 보정됩니다.

4. 선택하고 복사하기

글자를 드래그하면 파란색으로 선택됩니다. Ctrl+C로 텍스트를 복사합니다. 캡처 또는 Ctrl+Shift+C로 선택한 영역을 이미지로 복사하면 표·그래프·그림도 함께 담깁니다. 복사 알림이 나타나면 붙여넣을 앱에서 Ctrl+V를 누르세요. 표는 이미지로 복사되며 편집 가능한 셀로 변환되는 것은 아닙니다.

5. 페이지 정리와 문서 비교

병합·분할·페이지 추출로 문서를 정리하고 회전·페이지 번호를 적용할 수 있습니다. 비교에서 저장된 PDF 두 개를 선택하면 변경 목록과 나란한 미리보기가 열립니다. 현재 편집 내용을 비교하려면 먼저 저장하세요.

6. OCR로 Markdown 내보내기

OCR MD에서 대상 페이지를 정하고 내보냅니다. 한국어·영어 인식과 문단 배치를 처리하며 표·그림을 함께 담습니다. 이미지는 Markdown 안에 포함하거나 별도 폴더로 저장할 수 있습니다. OCR은 PC에서 처리되며 결과는 원본과 대조해 확인하세요.

자세한 안내와 문제 제보

앱에서 F1을 누르면 전체 사용안내가 열립니다. 전체 안내 소스와 GitHub 문제 제보도 이용할 수 있습니다. 공개 이슈에는 실제 도장이나 개인정보가 있는 문서를 첨부하지 말고, 가상의 예시로 재현해 주세요.
