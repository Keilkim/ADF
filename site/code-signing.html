CODE SIGNING POLICY

코드 서명과 배포.

macOS용 ADF 0.3.30은 Developer ID로 서명하고 Apple 공증을 받았습니다. Windows용 0.3.31은 현재 미서명 상태로 제공합니다.

2026년 9월 10일 SignPath Foundation에 무료 오픈소스 서명 지원을 신청했으나, 공개 인지도가 아직 부족하다는 이유로 9월에 승인되지 않았습니다. 유료 코드 서명 인증서를 검토하고 있으며 실제 서명은 아직 완료되지 않았습니다. Windows 설치 파일은 스마트 앱 컨트롤이나 SmartScreen에 의해 실행이 차단되거나 경고가 표시될 수 있습니다. 서명본이 준비되면 새 버전으로 게시하고 홈페이지 다운로드를 갱신합니다.

서명과 검증 현황

macOS용 앱과 DMG는 Apple Developer ID Application 인증서(SEONGHUN KIM, 팀 ID TZQ9JL6R7R)로 서명하고 Apple 공증을 받았습니다. 0.3.30 릴리즈 안내에서 파일 해시와 공증 결과를 확인할 수 있습니다.

Mac 소스 검사 386개와 세부 검사 129개, 앱 내부 기능 88개 항목, PDF 병합·분할·추출·압축 검사를 통과했고 Finder 설치·실행도 확인했습니다. PDF 기본 연결, 실제 입력 장치와 인쇄 조작, macOS 15 실기기 및 다른 Mac 설치는 추가 확인이 필요합니다.

Windows용 0.3.31은 소스 검사 401개와 세부 검사 136개, 탐색기 확장 구성 요소 검사 14,567개를 통과했습니다. Windows Server 2022에서 설치·설치된 파일 대조·앱 실행·문서 처리·제거도 확인했습니다. 해당 서버의 탐색기 메뉴 조합 검사는 실패했으며, Windows 10/11의 실제 탐색기 통합과 입력 장치는 추가 확인이 필요합니다. 릴리즈 안내에서 검증 범위와 파일 해시를 확인할 수 있습니다.

릴리즈 승인 담당자

현재 코드 작성·검토와 서명 승인 담당자는 저장소 유지관리자 Keilkim입니다. 서명 서비스를 연동한 뒤에도 각 릴리즈의 소스와 빌드 결과를 확인하고 유지관리자가 수동으로 서명을 승인합니다.

공개 소스와 배포 파일

ADF 자체 코드는 AGPL-3.0-or-later로 공개하며 외부 구성 요소에는 각 라이선스가 적용됩니다. 설치 파일과 대응 소스, 외부 라이브러리 소스 및 해시를 같은 릴리즈에서 제공합니다. 새 서명 또는 재빌드는 새로운 릴리즈로 게시합니다.

문서와 도장 보관

PDF 편집, 도장 보관, 비교와 OCR은 사용자 PC에서 처리합니다. 앱은 문서와 도장을 서버로 전송하지 않습니다. 자세한 내용은 데이터 보관 안내를 참고하세요.

For reviewers

ADF applied to the SignPath Foundation open-source program on September 10, 2026. The application was not approved in September 2026 because the project does not yet have enough public visibility; it may be resubmitted later. No release is signed by SignPath or the SignPath Foundation.

  • Committers and reviewers: Keilkim.
  • Signing approver: Keilkim. Each signing request requires manual approval.
  • Build system: a manually triggered GitHub Actions Windows workflow builds public source on GitHub-hosted runners and retains unsigned review artifacts. Windows 0.3.31 comes from that workflow and is published unsigned; workflow results are available at the link.
  • Installation, packaged app execution, document processing and uninstall passed on Windows Server 2022. This does not establish interactive Windows 10/11 compatibility. The hosted Windows Server Explorer menu check failed; its result remains visible separately in the build's summary and verification records.
  • The application does not upload user documents or stamp data. Website and download hosting are described in the privacy notice.
