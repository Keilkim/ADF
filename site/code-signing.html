CODE SIGNING POLICY

코드 서명과 배포.

현재 ADF 0.3.24는 서명되지 않은 Windows 사전 버전입니다.

SignPath Foundation의 무료 오픈소스 서명 지원 신청을 준비하고 있습니다. 아직 신청서 제출·지원 승인·서명은 완료되지 않았습니다. 현재 설치 파일은 Windows 스마트 앱 컨트롤에 의해 차단될 수 있습니다.

서명과 검증 현황

소스 자동 검사는 통과했지만 최종 설치 파일과 앱 EXE는 빌드 PC의 Windows Application Control에 의해 차단되어 설치·실행 검증을 완료하지 못했습니다. 릴리즈 안내에서 검증 범위와 파일 해시를 확인할 수 있습니다.

릴리즈 승인 담당자

현재 코드 작성·검토와 서명 승인 담당자는 저장소 유지관리자 Keilkim입니다. 서명 서비스를 연동한 뒤에도 각 릴리즈의 소스와 빌드 결과를 확인하고 유지관리자가 수동으로 서명을 승인합니다.

공개 소스와 배포 파일

ADF 자체 코드는 AGPL-3.0-or-later로 공개하며 외부 구성 요소에는 각 라이선스가 적용됩니다. 설치 파일과 대응 소스, 외부 라이브러리 소스 및 해시를 같은 릴리즈에서 제공합니다. 새 서명 또는 재빌드는 새로운 릴리즈로 게시합니다.

문서와 도장 보관

PDF 편집, 도장 보관, 비교와 OCR은 사용자 PC에서 처리합니다. 앱은 문서와 도장을 서버로 전송하지 않습니다. 자세한 내용은 데이터 보관 안내를 참고하세요.

For reviewers

ADF is preparing an application for the SignPath Foundation open-source program. The application has not been submitted or approved. No release is currently signed by SignPath or the SignPath Foundation.

  • Committers and reviewers: Keilkim.
  • Signing approver: Keilkim. Each signing request requires manual approval.
  • Build system: a manually triggered GitHub Actions Windows workflow builds public source on GitHub-hosted runners and retains unsigned review artifacts. The existing release was built locally. SignPath integration is pending; workflow results are available at the link.
  • The application does not upload user documents or stamp data. Website and download hosting are described in the privacy notice.
