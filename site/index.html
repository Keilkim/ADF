궁금한 점.

PDF나 도장이 서버에 올라가나요?

ADF 앱은 문서와 도장을 서버로 전송하지 않습니다. PDF 편집, 도장 보관, 비교, OCR 모두 사용자 PC에서 처리합니다. 이 사이트는 소개와 다운로드 안내용이며 문서 업로드 기능이 없습니다.

macOS에서도 사용할 수 있나요?

네. Apple Silicon Mac(M1 이후)의 macOS 15 이상에서 쓸 수 있습니다. Intel Mac은 OCR 구성 요소가 지원하지 않아 제공하지 않습니다. macOS 다운로드에서 받으세요.

인터넷 없이도 사용할 수 있나요?

설치 파일을 내려받은 뒤에는 인터넷 없이 설치하고 문서 작업을 할 수 있습니다. Python과 OCR 모델을 포함한 실행 구성 요소가 설치 파일 안에 들어 있습니다. 인터넷에 연결되면 새 버전을 확인해 받아 두고 알려 주며, 앱의 도움말 메뉴에서 끌 수 있습니다.

설치 파일이 차단되면 어떻게 하나요?

macOS 앱은 Apple 공증을 받았습니다. Windows용은 아직 미서명이며, 스마트 앱 컨트롤이나 SmartScreen이 실행을 차단하거나 경고할 수 있습니다. 서명본은 준비되는 대로 새 버전으로 제공합니다. 진행 상황은 코드 서명 안내와 GitHub 릴리즈에서 안내합니다.

무료로 사용하고 수정할 수 있나요?

ADF 자체 코드는 AGPL-3.0-or-later로 공개합니다. 사용·수정·재배포할 수 있으며, 배포 시 해당 라이선스 조건을 따라야 합니다. 외부 라이브러리에는 각 라이선스가 적용됩니다. 라이선스 안내에서 원문과 소스 제공 정보를 확인하세요.

사용법을 다시 보고 싶어요.

앱의 도움말 → 기능 둘러보기에서 처음 안내를 다시 볼 수 있습니다. F1 또는 도움말 → 사용안내로 자세한 설명을 열 수 있고, 사이트 사용안내도 이용할 수 있습니다.
