문서는 내 PC에.

ADF는 PDF 편집과 도장 보관, 문서 비교, OCR을 사용자 PC에서 처리하는 데스크톱 앱입니다.

PDF와 도장

문서는 사용자가 지정한 위치에서 읽고 저장합니다. 등록한 도장의 이미지·이름·너비는 Qt의 사용자별 로컬 앱 데이터 폴더 아래 stamps.sqlite3에 저장됩니다. 원본 도장 이미지의 경로는 보관하지 않습니다. 앱은 문서와 도장을 서버로 업로드하지 않습니다.

도장 보관함은 암호화된 금고 기능을 제공하지 않습니다. 같은 Windows 계정으로 이 파일에 접근할 수 있는 프로그램은 데이터를 읽을 수 있습니다. PC의 계정 접근 권한을 관리해 주세요.

백업과 다른 PC로 옮기기

ADF를 완전히 종료한 뒤 로컬 앱 데이터 폴더의 stamps.sqlite3를 별도로 복사해 보관할 수 있습니다. 다른 PC로 옮기거나 기존 파일을 교체하기 전에는 그 PC의 보관함도 먼저 백업하세요. ADF 자체의 자동 클라우드 동기화 기능은 없습니다.

사용자가 PDF를 OneDrive 같은 동기화 폴더에 저장하거나 별도의 백업 프로그램을 사용하면 해당 서비스의 설정에 따라 파일이 동기화될 수 있습니다.

OCR과 앱 설정

OCR 모델은 설치 파일에 포함되며 문서 인식은 PC에서 실행됩니다. 창 배치와 기능 투어 확인 상태 등은 로컬 앱 설정에 저장합니다. 오류가 발생하면 로컬 앱 데이터 폴더에 오류 로그가 남을 수 있습니다. 자동 전송이나 원격 분석 기능은 추가하지 않았습니다.

업데이트 확인

설치한 앱은 인터넷에 연결되어 있을 때 GitHub에서 최신 버전 번호와 체크섬 목록을 확인하고, 새 버전이 있으면 설치 파일을 받아 로컬 앱 데이터 폴더에 둡니다. 요청에는 앱 버전만 담기며 문서, 파일 이름, 도장, 사용 기록은 보내지 않습니다. 이 과정에서 GitHub가 IP 주소 등 운영 로그를 처리할 수 있습니다. 앱의 도움말 → 업데이트 자동 확인에서 끌 수 있습니다.

이 웹사이트와 다운로드

이 사이트는 소개·사용안내·다운로드 링크를 제공합니다. 파일 업로드, 회원가입, 도장 보관 기능이 없고 별도의 분석 스크립트나 광고를 넣지 않았습니다. 사이트는 Vercel에서, 소스와 설치 파일은 GitHub에서 제공합니다. 접속·다운로드 과정에서 각 호스팅 서비스가 IP 주소 등 운영 로그를 처리할 수 있습니다.
