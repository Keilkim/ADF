# ADF 0.3.11 통합 릴리즈 검증

2026-09-09, Windows x64 / Python 3.12.

## 포함 범위

- 현재 작업 폴더의 전체 소스에서 빌드한다. 이전 독립 클립보드 수정용 작업 폴더는 빌드 입력으로 사용하지 않는다.
- PDF 두 버전 비교, 저용량 저장 오른쪽 도장 보관함, 등록·관리 팝업, 기본 20mm 너비, 등록된 도장의 클릭 연속 배치, 회색 선택 카드·호버 수정/삭제, 실행 취소·다시 실행·저장, 페이지 위치 안정화를 포함한다.
- 사용하지 않는 손상 PDF 객체로 인한 `code=8: invalid key in dict` 수정과 0.3.10의 클립보드·압축 관련 수정도 유지한다.

## 검사 기록

- 전체 Python 검사: 174개 및 하위 검사 96개 통과. `.tools/verification/pytest-0.3.11.xml`.
- 소스 앱 smoke: 기존 문단 편집·페이지 번호·이미지 페이지 추가 검사에 도장 팝업 자동 입력, 동일 도장 3회 클릭 배치, 너비 변경, 수정·삭제·복원, Esc 종료, 저장 및 실제 비교 작업 프로세스를 추가해 통과했다. 합성 PDF·이미지와 임시 보관함만 사용한다.
- 설치본도 같은 `--smoke-test`를 실행한다. 설치된 모든 파일을 빌드 폴더와 SHA-256으로 대조하고, 임시 설치·제거 전후 기존 ADF 설치와 PDF 연결을 비교한다. 결과는 `release/installer-smoke-0.3.11.json`에 기록한다.
- `scripts/verify-release.py`는 소스 ZIP 전체 파일, 실행파일에 들어간 모든 ADF 모듈의 코드, 포함 리소스, 외부 소스 8개 및 배포 파일 해시를 대조한다. 결과는 `release/release-audit-0.3.11.json`에 기록한다.
- C++ 탐색기 확장과 테스트 도구 컴파일은 성공했다. 새 테스트 도구 실행은 Windows Application Control에 차단되어 네이티브 선택 메뉴 검사는 생략한다. 보안 정책은 변경하지 않는다. 이 생략은 설치 검증 JSON에도 기록한다.

macOS 빌드와 회사 배포용 코드 서명은 이번 검증 범위에 포함하지 않는다.
