# ADF 0.3.24 필기 도구·크기 미리보기·선택 표시

2026-09-10

## 변경

- 첫 실행의 소개창을 실제 상단 버튼을 짚는 6단계 투어로 바꿨습니다. 이전·다음, 건너뛰기, Esc, 도움말 연결을 지원합니다. 완료·건너뛰기는 사용자 설정에 즉시 저장하고 도움말에서 언제든 다시 엽니다. 기존에 소개창을 닫은 사용자의 설정은 유지합니다.
- 텍스트·이미지·캡처를 복사하면 클립보드 복사 완료와 Ctrl+V 안내가 문서 아래에 2.6초 나타납니다. 입력 초점을 가져가지 않으며 전체화면에서도 표시합니다. 화면 읽기 프로그램에 알림을 전달합니다.
- 펜과 지우개를 별도 버튼으로 분리했습니다. 버튼 본체는 토글하며 오른쪽 아래 대각선 화살표로 옵션을 엽니다. 옵션 밖의 첫 마우스·태블릿 입력은 창만 닫습니다.
- 옵션은 테두리 없는 회색 선택 배경과 둥근 네 모서리를 유지하면서 펜 304px, 지우개 248px 폭으로 줄였습니다. 실제 높이는 시스템 글꼴과 화면 배율에 따라 달라집니다.
- 펜슬·마카·브러쉬는 실제 필기 렌더러로 굵기·색상·투명도를 미리 보여 줍니다. 지우개는 원으로 크기를 표시합니다. 슬라이더 변경 즉시 반영하며 오른쪽 아래에 미리보기 배율을 표시합니다.
- 거의 직선인 필기를 누른 채 약 0.6초 멈추면 시작점과 끝점을 잇는 직선으로 정리합니다. 이후 움직임은 그 방향으로 투영해 길이만 조절합니다. 곡선·낙서·짧은 점은 보정하지 않으며 페이지를 벗어나거나 Esc로 취소하면 대기 중인 보정도 취소합니다.
- 스냅에 자석 아이콘, 펜과 캡처에 이름을 붙였습니다. 열기·저장·다른 이름으로 저장·비교·OCR MD는 상단에서 아이콘만 표시하고 툴팁·접근성 이름은 유지합니다. 다른 이름 저장은 겹친 디스크, OCR MD는 눈과 겹친 문서 아이콘입니다.
- 드래그 중 회색 영역, 완료 후 움직이는 파선으로 선택을 표시합니다. 일반 글자 선택은 글자 위치에 파란 강조를 표시하고, 캡처는 파선만 표시합니다. 선택을 해제하면 모두 사라집니다. Windows 애니메이션 설정을 따릅니다.
- 미리보기·파란 강조·파선은 PDF와 복사 이미지에 포함되지 않습니다. 이미지·그래프·표를 함께 복사하려면 캡처 또는 Ctrl+Shift+C를 사용합니다.

## 검증 범위

자동 검사는 펜·지우개 본체/화살표의 실제 클릭, 팝업 밖 마우스·태블릿 입력 차단, 각 도구의 굵기·색상 미리보기 갱신, 옵션 크기, 누른 상태의 직선 전환·방향 유지·실행 취소·다시 실행·PDF 저장을 확인합니다. 회전 0/90/180/270도와 CropBox가 있는 페이지도 포함합니다.

선택 검사는 파란 강조 위치, 회전·확대와의 일치, 파선 이동, 애니메이션 비활성화, 선택 해제·문서 종료의 정리를 확인합니다. 캡처 결과를 PDF에서 직접 렌더링한 이미지와 비교해 선택 표시가 섞이지 않는지도 확인합니다. 실제 글꼴을 등록한 Qt 화면을 이미지로 확인합니다.

투어 검사는 첫 실행 감지·건너뛰기 저장·도움말 재진입·6단계 전환·이전 단계·Esc·창 크기 변경·프로그램 종료를 포함합니다. 복사 알림은 실제 클립보드 내용, 입력 초점 유지, 전체화면 배치, 자동 숨김, 문서 종료 후 정리를 확인합니다.

정식 릴리즈 결과는 `release/배포상태-0.3.24.md`에 기록합니다. 전체 회귀 검사, 소스와 EXE의 일치, 설치 파일과 격리 설치 파일의 해시, 설치된 앱의 필기·선택·OCR·작업 프로세스 검사를 수행합니다. 기존 Windows Application Control이 차단한 네이티브 검사 실행 파일과 제거 프로그램은 재실행하지 않고 검증 제외로 기록합니다. 실물 스타일러스의 필기감과 외부 앱별 붙여넣기는 별도 확인 대상입니다.
