# XDF 0.3.42 Windows 검증 기록

검증·게시일: 2026년 10월 4일 (한국시간).

Windows용 XDF 0.3.42입니다.

[공식 홈페이지·다운로드](https://adf-desktop.vercel.app) · [사용안내](https://adf-desktop.vercel.app/guide)

## 바뀐 동작

- 여러 XDF 창을 열었을 때 업데이트 알림이 같은 화면 위치에 겹치던 문제를 고쳤습니다. 백그라운드 실행 또는 업데이트를 담당하는 창 하나에서만 알립니다.
- 업데이트 버튼을 반복해서 눌러도 설치용 창을 한 번만 엽니다. 설치 시작을 기다리는 동안 같은 버전의 알림과 창을 반복해서 띄우지 않으며, 설치가 진행되지 않으면 약 2분 뒤 알림이 돌아옵니다.

macOS는 기존 [ADF 0.3.30](https://github.com/Keilkim/ADF/releases/tag/v0.3.30)을 제공합니다. Windows 10 1809 이상 / Windows 11의 Intel·AMD x64 PC용입니다. Windows 파일은 미서명이며 보안 정책에 따라 실행 경고나 차단이 있을 수 있습니다.

## 검증 결과

- [Windows 빌드·검증](https://github.com/Keilkim/ADF/actions/runs/37133362986): 소스 검사 526개와 세부 검사 170개 통과, 환경·선택 의존성에 따른 검사 17개 건너뜀. 탐색기 확장 구성 요소 검사 13,688개 통과.
- Windows Server 2022에서 설치·파일 1,051개 해시 대조·앱 실행·문서 처리·독립 도구 창·제거를 확인했습니다.
- 0.3.37~0.3.41에서의 업데이트 패치 5개가 파일 대조·문서와 함께 재실행·다른 버전 적용 거부·제거 검사를 통과했습니다.
- 대응 소스 파일 692개, 실행 파일 내부 모듈 53개와 리소스 552개를 대조했습니다. 빌드 원본은 커밋 `860c3cb1eb68dfad9fc3fd6d84502ec567f95af4`입니다.
- **검증 제한:** Windows Server의 탐색기 메뉴 조합 검사는 기존과 동일하게 실패했습니다. Windows 10/11의 실제 탐색기 통합과 입력 장치 전체 검증이 완료됐다는 의미는 아닙니다. 결과는 빌드 기록과 `ADF-Build-0.3.42-Windows.json`에 명시했습니다.

