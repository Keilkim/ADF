# XDF 0.3.45 복사·한글 변환 검증

검증일: 2026년 10월 7일 (한국시간).

PDF에서 한글 단어 사이를 공백 문자 없이 글자 위치로만 표현하면 텍스트 복사에서 띄어쓰기가 빠졌습니다. 선택·영역 복사·편집 문단·HWPX 로컬 추출에서 같은 공백 복원 처리를 사용합니다. 빈 글리프가 `$` 또는 Unicode 없는 CID 36으로 잘못 추출되는 경우도 공백으로 복원하며 실제 통화 기호는 유지합니다. PDF 원본은 바꾸지 않습니다.

HWPX 변환은 문단 안의 서로 다른 글꼴·크기·굵기·기울임·색과 셀별 서식을 보존합니다. 표의 병합, 비균등 열 너비·행 높이, 셀 안쪽 여백·정렬, 배경색, 각 방향 테두리의 두께·색·선 종류를 반영합니다. 선 두께는 HWPX가 지원하는 값 중 가장 가까운 값으로 저장합니다. Gemini 구조에도 셀 서식을 추가하고, 같은 표와 글자로 식별되는 경우 PDF에서 측정한 서식을 우선 사용합니다.

## 복사 재현 검사

- 한국어·영어·반복 공백, 16pt 한글 단어의 위치 간격 2/3/4/6pt, 잘못된 공백 매핑과 Unicode 없는 CID, 저장소의 글꼴 미리보기 PDF 등 10개 문서를 검사했습니다. 수정 후 앱의 드래그 선택 및 클립보드 내용이 예상값과 일치했습니다.
- Mac의 실제 클립보드와 Word 16.113.4의 새 문서에 붙여넣기를 검사했습니다. `계약 해지 조건 안내`의 공백 3칸과 `AB C $100`의 공백·실제 통화 기호가 그대로 유지됐습니다. 검사 문서는 저장하지 않고 닫았습니다.
- 회전 0/90/180/270도, 일정한 자간 및 단어 사이 간격 구분, 일본어 문구, 영역 복사, PDF 원본 바이트 보존을 자동 검사합니다.
- 사용자가 증상을 본 특정 PDF는 제공되지 않아 해당 파일 자체를 검사한 결과는 아닙니다. 간격만으로 표현된 단어 경계는 추정이며 모든 문서의 원래 공백 수를 복원한다고 보장하지 않습니다.

## HWPX 서식 검사

- 18pt 굵은 빨간 글자와 8pt 기울인 파란 글자를 서로 다른 셀에 넣고, 80/220pt 열 너비와 40/70pt 행 높이를 가진 표를 변환했습니다.
- 빨간 2pt 외곽선, 초록 0.5pt 내부선, 파란 1pt 파선과 셀 배경색을 저장한 HWPX의 XML에서 대조했습니다. 한글 선 두께로 각각 0.7mm, 0.2mm 등 가장 가까운 지원 값을 확인했습니다.
- 혼합 문단의 20pt 굵게·12pt 기울임과 색, 셀 텍스트·병합·크기, 보이지 않는 테두리, AI 구조의 이중선·점선, 잘못된 서식 거부를 검사합니다. 변환 결과의 ZIP·XML 스키마 검증과 다시 열기를 완료했습니다.
- AI가 수정한 텍스트를 덮어쓰지 않으면서 측정한 셀 서식을 재사용하는 경우를 확인했습니다. 이번 서식 확장의 실제 온라인 AI 호출은 별도로 실행하지 않았습니다.

## 검증 범위와 배포

Mac의 글꼴 검사에서는 실제 ExtraBold 파일의 OpenType 두께 800과 선택된 스타일을 확인했습니다. macOS가 이를 두께 900으로 보고하는 경우를 허용하며 Cocoa 검사에서 실제 선택한 파일도 대조합니다. 좁은 글자의 중간점을 화면 픽셀 반올림이 넘는 선택 검사 좌표를 수정했습니다.

빌드 원본 커밋은 `0d407727ffa64d728d5071e2c3af8986a6c3bbf5`입니다. 아래 검증 결과와 홈페이지 안내는 빌드 후 추가한 배포 기록입니다. 대응 소스 ZIP은 각 플랫폼의 실제 빌드 입력을 담습니다.

- macOS 전체 소스 검사 **587개**, 세부 검사 **167개** 통과, 선택 의존성·환경에 따른 검사 25개 건너뜀. 관련 검사 113개와 세부 검사 7개 통과. Cocoa에서 실제 글꼴 스타일·파일을 별도로 확인했습니다.
- Mac 배포 앱에서 PDF 편집·저장·도장·필기·비교·OCR·뜻 검색과 독립 도구, 병합·분리·추출·압축, 원본·기존 결과 보존 검사가 통과했습니다.
- Mac 앱과 DMG의 Developer ID 서명·Apple 공증·티켓 첨부 및 Gatekeeper 허용을 확인했습니다. 실제 DMG를 마운트해 앱의 파일·링크 **1,261개**를 검증한 앱과 대조했고, DMG 안의 앱으로 HWPX 셀 서식 변환도 확인했습니다. Mac 소스 **738개**, 내부 모듈 **58개**, 리소스 **574개**, 외부 라이브러리 소스 **37개**를 대조했습니다.
- Mac 배포 앱의 HWPX 작업 프로세스로 서식 예제를 변환하여 18pt/8pt 셀 글자 크기, 80/220pt 열 너비와 0.7mm 빨간 실선을 다시 대조했습니다. ZIP·XML 검증과 다시 열기를 통과했습니다.
- [Windows 빌드·설치·업데이트 검사](https://github.com/Keilkim/ADF/actions/runs/37619072155): 소스·OCR 검사 **595개**, 세부 검사 **174개**, 탐색기 확장 구성 요소 **13,688개** 통과, 선택 의존성·환경에 따른 검사 17개 건너뜀. Windows Server 2022에서 설치 파일 **1,145개**의 해시·앱 실행·도움말·OCR·독립 도구·문서 처리·제거를 확인했습니다.
- 0.3.43 및 0.3.44에서 0.3.45로 업데이트하는 패치를 적용해 파일 목록·앱 실행·기존 결과·실제 설치 보존과 제거를 확인했습니다.
- [Windows 자산 준비·배포 앱 HWPX 검사](https://github.com/Keilkim/ADF/actions/runs/37621376305)에서 성공한 빌드의 설치 파일·대응 소스·해시를 다시 확인했습니다. 설치 파일에서 꺼낸 공개 앱으로 셀별 글자 크기·굵기·기울임·색, 비균등 열/행 크기, 각 방향 테두리·편집 가능한 텍스트와 API 키 제외를 확인했습니다. 같은 검사 스크립트를 Mac 앱에서도 통과했습니다.
- Windows 대응 소스 파일 **738개**, 실행 파일 내부 모듈 **58개**, 리소스 **588개**를 대조했습니다. 외부 라이브러리 소스 38개, OCR 모델 5개와 뜻 검색 모델 2개를 확인했습니다. 서버의 탐색기 메뉴 조합 검사는 기존과 동일하게 실패했고, Windows 10/11의 실제 탐색기 통합·입력 장치는 별도 확인이 필요합니다.

Mac용 공개 빌드는 Apple Silicon 대상이며 macOS 15 이상입니다. Windows 공개판은 미서명이며 개인 Gemini API 키를 포함하지 않습니다.

모든 PDF를 원본과 100% 동일한 편집 가능한 한글 문서로 변환한다고 보장하지 않습니다. 글꼴 파일을 포함하지 않으므로 해당 PC에 없는 글꼴은 대체될 수 있습니다. 복잡한 배치·수식·회전 글자·스캔 문서는 대조가 필요합니다. 현재 컴퓨터의 접근성 권한이 허용되지 않아 한컴 한글에서의 자동 붙여넣기·화면 대조는 수행하지 못했습니다. HWPX 서식 검사와 Word 붙여넣기를 한컴 한글의 실제 표시 검사로 대신 주장하지 않습니다.
