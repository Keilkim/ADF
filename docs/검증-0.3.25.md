# ADF 0.3.25 Mac 앱·도구 묶음·페이지 번호 삭제

2026-09-10

## 변경

- Apple Silicon Mac(macOS 15 이상)용 앱과 DMG를 추가했습니다. 사용안내·라이선스·대응 소스·OCR 모델을 앱에 넣어 인터넷 없이 사용합니다. PySide6 6.11.2의 Apple Silicon용 모듈이 macOS 15 기준이고, ONNX Runtime 1.29.0은 Intel Mac용 배포 파일이 없어 Intel Mac은 지원하지 않습니다.
- Mac 빌드는 PyPI의 OpenCV wheel이 담은 FFmpeg와 GPL 영상 코덱 대신, 같은 버전의 OpenCV 원본 소스를 수정 없이 영상 입출력 없이 컴파일해 사용합니다. Mac 앱의 고지는 macOS wheel에서 따로 모읍니다.
- Mac 앱과 DMG는 Developer ID로 서명하고 hardened runtime을 적용합니다. 공증 자격 증명을 지정하면 앱과 DMG를 공증하고 결과를 붙입니다.
- Mac 배포의 대응 소스·외부 라이브러리 소스·해시 파일에는 `-macOS`를 붙여 Windows 파일과 구분합니다. 앱 안의 소스 파일 이름은 그대로입니다.
- 상단 첫 줄의 다른 이름 저장 오른쪽에 저용량 저장 아이콘(오른쪽 아래에 아래쪽 화살표가 있는 디스크)을 두었습니다.
- 둘째 줄 도구를 분할·페이지 추출 | 오른쪽·왼쪽 회전 | 페이지 번호·번호 삭제 | 이미지·텍스트 수정·펜·지우개 | 스냅·캡처·도장 보관함으로 묶고 옅은 구분선으로 나눴습니다. 창이 좁으면 묶음 단위로 다음 줄에 이어집니다. 교체는 상단에서 빼고 왼쪽 페이지 패널과 페이지 메뉴에 둡니다.
- 캡처도 펜·지우개처럼 한 번 더 누르면 해제됩니다.
- ADF가 넣은 페이지 번호의 글자와 위치를 페이지에 기록합니다. 다시 번호를 적용하면 기록된 번호를 새 설정으로 바꾸고, 번호 삭제는 기록된 번호만 지웁니다. 기록된 위치에 다른 글자가 겹쳤거나 번호를 직접 고친 페이지는 건드리지 않습니다. 이전 버전이나 다른 프로그램에서 넣은 번호, 분할·추출·병합으로 만든 새 PDF의 번호는 기록이 없어 지우지 않습니다.
- Mac의 시작 안내 PDF는 원본 글꼴로 계속 편집할 수 있도록 TrueType인 AppleGothic을 넣습니다. Apple SD Gothic Neo 같은 CID-keyed CFF 내장 글꼴은 이전과 같이 재사용하지 않습니다.

## 검증 범위

자동 검사는 macOS 26.3.1 Apple Silicon Mac에서 전체 268개 통과, Windows 전용 3개 건너뜀, 세부 검사 115개 통과입니다. Windows 글꼴을 전제로 하던 한글 OCR·입력 검사는 각 운영체제의 한글 시스템 글꼴을 사용합니다.

번호 삭제 검사는 회전 0/90/180/270도 페이지, 본문과 다른 프로그램이 넣은 같은 글자의 번호, 다시 적용할 때의 교체, 겹친 글자와 직접 고친 번호의 보존, 저장 후 다시 열기, 실행 취소, 번호 미리보기와 적용 결과의 일치를 확인합니다. 도구 줄 검사는 묶음 순서, 좁은 창에서 묶음 단위 줄바꿈과 구분선 위치, 저용량 저장 아이콘의 위치, 펜·지우개·캡처의 해제를 확인합니다.

Mac 설치 앱은 서명한 앱 번들의 스모크 검사(편집·도장·비교·인쇄·전체 화면·도움말·소스·OCR·번호 삭제), 작업 프로세스 검사, 소스와 앱의 일치·영상 코덱과 끊어진 링크 없음·실행 파일의 최소 macOS를 확인하는 패키지 정적 검사를 수행합니다. 정식 릴리즈 결과는 `release/배포상태-0.3.25-macOS.md`와 `release/배포상태-0.3.25.md`에 기록합니다.

이 버전의 Windows 설치 파일은 Windows에서 빌드해 검증해야 합니다. `ADF.spec`의 Qt 링크 필터 변경과 도구 줄 변경을 Windows 빌드와 설치 앱에서 확인합니다. Mac 공증, Finder 연결, 실제 화면 조작(트랙패드·한글 입력·인쇄), macOS 15 실기기 실행과 다른 Mac에서의 설치는 별도 확인 대상입니다.
