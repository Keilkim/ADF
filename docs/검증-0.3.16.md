# ADF 0.3.16 사용안내와 오픈소스 배포 자료

2026-09-09, Windows x64 / Python 3.12.

## 변경 사항

- F1 또는 도움말 메뉴에서 사용안내를 연다. 목차와 본문 검색을 제공하며, PDF 작업과 함께 열어 둘 수 있다. Esc로 닫는다.
- 같은 창의 오픈소스 라이선스 탭에서 구성 요소별 원문을 읽는다. 라이선스 안내의 원문 링크도 창 안에서 열린다. ADF의 AGPL 권리·무보증 고지를 표시한다.
- 설치 파일 안에 해당 버전의 ADF 소스 ZIP과 외부 라이브러리 소스 ZIP, SHA-256 목록을 넣는다. 도움말의 소스코드 탭에서 설치된 소스 폴더를 연다. 개발 실행 환경에 소스 묶음이 없으면 없다고 표시한다.
- 시작 메뉴에서 오프라인 사용안내 HTML, 읽을 수 있는 라이선스 HTML, 소스 폴더를 연다. 모든 자료를 정식 Setup EXE 하나에 포함한다.
- 소스 ZIP을 먼저 만들고 실행 폴더와 설치 파일에 포함한다. 배포용 별도 ZIP은 포함된 파일을 그대로 복사하며, 현재 코드와 불일치하면 패키징을 중단한다.

## 검증 범위

- 도움말 검색·검색 결과 없음·원문 동일성·탭 이동·창 재사용·Esc·첫 안내에서 도움말 진입·앱과 함께 닫기를 검사한다. 도움말 열람에서 외부 프로그램을 자동 실행하지 않는지 확인한다.
- 설치된 소스 발견과 누락 안내를 각각 확인한다. 실행 파일의 smoke test에서는 포함된 두 소스 ZIP을 열어 앱과 라이브러리 manifest 버전이 맞는지 검사한다.
- 배포 검증은 현재 코드, 소스 ZIP, 실행 파일 내부 코드, 안내·라이선스 리소스, 내장 소스와 별도 배포 소스의 해시 일치를 확인한다.
- 설치 검증은 임시 폴더와 전용 레지스트리에 설치하고 자료와 바로가기 대상을 확인한다. 모든 설치 파일의 해시를 빌드 폴더와 비교하며, 기존 사용자 설치와 PDF 연결 보존을 검사한다.

실제 검사 결과와 실행 환경의 제한은 `release/배포상태-0.3.16.md`에 기록한다. 테스트는 법적 판단을 대신하지 않는다. 사용한 라이선스 원문과 대응 소스를 함께 제공하는 구조에 대한 기술 검증이다.
