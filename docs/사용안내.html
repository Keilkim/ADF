ADF

PDF 작업을 가볍게.

문서를 읽고, 필요한 페이지를 정리하고, PDF로 저장하세요.
계정이나 인터넷 연결 없이 이 컴퓨터에서 작업합니다.

OCR로 Markdown 내보내기

상단 OCR · MD 또는 파일 → OCR · Markdown 내보내기…를 선택하세요. 전체 / 현재 / 왼쪽에서 선택 / 직접 입력 중 페이지를 고릅니다. 직접 입력에는 1,3,5-8처럼 번호와 범위를 함께 씁니다.

기본 자동은 PDF에 있는 글자를 우선 사용하고 필요한 영역을 한글·영어 OCR로 읽습니다. 스캔은 OCR로 처리합니다. 저장 위치와 문서 이름을 정하고 내보내기 시작을 누르세요. 저장 전 수정 내용도 포함되며 기존 폴더는 덮어쓰지 않습니다.

이미지 저장에서 MD 안에 이미지 포함 · Base64 (기본) 또는 이미지 폴더로 분리를 고르세요. 기본값은 그림 데이터를 MD 안에 넣으므로 MD 파일만 복사해도 이미지가 함께 유지됩니다. MD 용량은 커지며 일부 Markdown 뷰어에서는 내장 이미지가 표시되지 않을 수 있습니다. 이 경우 이미지 폴더 분리를 사용하세요.

새 결과 폴더와 MD 이름은 날짜_문서이름_고유ID입니다. 예를 들어 20260909_보고서_a1b2c3d4e5f6/20260909_보고서_a1b2c3d4e5f6.md로 저장합니다. 분리 방식의 이미지는 그 안의 images/20260909_보고서_a1b2c3d4e5f6_p00001_001.png처럼 페이지·이미지 번호를 덧붙입니다. MD에는 상대경로를 기록하므로 결과 폴더 전체를 함께 옮기세요. 고유한 이름만으로 따로 이동한 이미지를 자동 검색하지는 않습니다.

일반 표는 Markdown 표로, 병합 셀은 HTML 표로 저장합니다. 그래프와 도형은 그림으로 보존합니다. 확인용 전체 페이지 이미지도 선택한 이미지 저장 방식에 따릅니다. 분리 방식에서는 pages에 저장하므로 이 폴더도 함께 옮기세요.

작업 창에는 현재 단계와 처리한 페이지 수를 표시합니다. 취소 또는 Esc를 누르면 진행 중인 OCR도 멈추고 임시 결과를 정리합니다. 완료된 묶음만 저장 위치에 나타납니다.

모델과 실행 구성 요소는 정식 설치 파일에 포함됩니다. 문서를 외부로 전송하거나 모델을 추가로 다운로드하지 않습니다. 흐린 스캔·작은 글자·복잡한 배치는 오인식할 수 있습니다. conversion.json의 확인 항목과 원본 이미지를 비교하세요. layout.json에는 읽는 순서·영역 위치·인식 확신도를 남깁니다. PDF의 복사 제한도 적용됩니다.

PDF를 여는 동안 진행 상황 보기

PDF를 열면 파일 읽기 → PDF 구조 확인 → 페이지 확인 → 첫 페이지 준비 → 편집할 문서 준비의 실제 작업을 표시합니다. 읽은 바이트와 확인한 페이지 수가 있는 단계는 그 수로 퍼센트를 계산합니다. 전체 처리량을 알 수 없는 단계는 단계명과 스피너로 표시하며 임의로 퍼센트를 올리지 않습니다.

취소 또는 Esc로 열기를 중단할 수 있습니다. 취소하거나 암호 입력을 닫으면 기존에 열어 둔 문서와 저장하지 않은 수정 내용은 유지됩니다.

PDF만 전체화면으로 보기

상단의 여러 장 보기 아이콘 오른쪽에 있는 전체 화면 버튼 또는 F11을 누르세요. 창 테두리·메뉴·왼쪽 미리보기·하단 페이지 번호를 숨기고 PDF만 화면 전체에 표시합니다.

마우스를 화면 상단 가장자리로 가져가면 메뉴와 도구, 왼쪽은 페이지 미리보기, 하단은 페이지 번호와 이동 버튼이 슬라이드로 나타납니다. 도구 밖으로 벗어나면 다시 숨겨집니다. 페이지 번호 입력이나 펼친 메뉴를 조작하는 동안에는 도구가 유지되며, 도구가 나타나도 PDF 크기는 바뀌지 않습니다.

Esc·F11 또는 문서 더블클릭으로 전체화면을 해제합니다. 읽던 페이지를 유지하면서 이전 창 크기·미리보기 너비·확대 설정으로 돌아옵니다. PgUp / PgDn으로도 페이지를 넘깁니다. Windows에서 애니메이션 효과를 끈 경우 도구는 이동 효과 없이 나타납니다.

텍스트와 이미지 선택하기

캡처 버튼 또는 편집 → 영역 복사를 누르고 드래그하면 글·그림·그래프·표·필기를 함께 이미지로 복사합니다. 캡처 버튼을 한 번 더 누르면 해제됩니다. 복사되면 문서 아래에 복사되었습니다 · 클립보드 알림이 잠시 나타납니다. 텍스트·이미지 복사와 전체화면에서도 같은 알림을 표시합니다. 다른 앱에서 Ctrl+V로 붙여넣으세요. 이미 선택한 영역은 Ctrl+Shift+C로 이미지 복사할 수 있습니다. 표는 모양을 유지한 그림으로 복사하며, 편집 가능한 엑셀 셀로 변환하지 않습니다.

오른쪽 문서 화면은 기본으로 선택 도구를 사용합니다. 글자 위에 마우스를 올리면 커서가 I 모양으로 바뀝니다. 드래그 중에는 회색 영역이 보이고, 선택을 마치면 글자 뒤에 파란 강조와 영역 가장자리에 움직이는 파선이 나타납니다. 캡처도 같은 파선으로 표시합니다. 선택을 해제하면 강조와 파선이 사라지며, 표시 자체는 PDF나 복사 이미지에 들어가지 않습니다. Windows 애니메이션을 끄면 파선은 움직이지 않습니다. 드래그해 텍스트를 선택하고 Ctrl + C로 복사하세요. 텍스트가 포함되지 않은 스캔 이미지는 글자로 선택되지 않습니다.

이미지는 클릭해서 선택합니다. Ctrl + C로 이미지를 복사하거나 Delete로 삭제할 수 있습니다. Esc 또는 빈 곳 클릭으로 선택을 해제합니다. 문서를 끌어 움직이려면 상단 보기 → 손 도구를 고르세요. 다시 글자나 이미지를 선택하려면 보기 → 선택 도구로 돌아옵니다. PDF에 복사·편집 제한이 있으면 해당 작업은 제한됩니다.

인쇄하기

Ctrl + P 또는 인쇄 버튼을 누릅니다. 전체 / 현재 페이지 / 선택한 페이지 / 페이지 직접 입력 중 대상을 고르세요. 1,3,5-8처럼 번호와 범위를 함께 입력할 수 있습니다.

용지에 맞춤 / 큰 페이지만 축소 / 실제 크기 / 배율 지정 중 크기를 고른 뒤 프린터 선택…에서 프린터, 용지, 방향과 매수를 정합니다. 용지에 맞춤은 인쇄 가능한 영역 안에 비율을 유지해 배치합니다. 실제 크기와 직접 지정한 배율에서는 영역을 벗어난 부분이 잘릴 수 있습니다.

선택한 페이지 추출하기

왼쪽에서 Ctrl / Shift로 페이지를 고른 뒤 상단 페이지 추출 또는 우클릭·파일 메뉴의 선택 페이지 추출…을 누릅니다. 범위를 확인하고 다른 이름으로 저장…에서 파일명과 저장 위치를 지정하세요. 저장 전 수정 내용도 새 PDF에 포함되며 원본과 현재 작업은 유지됩니다.

왼쪽 패널의 경계선을 넓히면 미리보기 크기를 유지하면서 완전히 들어가는 열 수가 늘어납니다. 좁히면 열 수가 줄고 나머지 페이지는 아래로 이어집니다. 페이지 번호 입력칸도 전체 페이지 수의 자릿수에 맞춰 넓어집니다.

도장 보관함

상단 도구 줄 맨 오른쪽의 도장 보관함을 누릅니다. 오른쪽 도장 등록하기를 누르고 팝업에서 PNG/JPG 파일을 불러온 뒤 이름과 너비(기본 20mm)를 저장하세요.

등록된 도장 미리보기를 클릭하면 카드가 테두리 없는 짙은 회색으로 선택되고 스탬프 모드가 됩니다. 마우스를 따라오는 미리보기를 보면서 PDF를 클릭할 때마다 바로 찍습니다. Esc 또는 우클릭으로 종료합니다. 도장은 클릭 한 번씩 실행 취소할 수 있으며 마지막에 PDF를 저장하세요. 투명 배경·비율은 유지하며 페이지보다 큰 도장은 들어갈 크기로 줄입니다.

카드 위에 마우스를 올리면 이름 수정하기 / 삭제가 나타납니다. 이름 수정하기는 도장 관리 팝업을 열어 이미지·이름·너비를 바꿉니다. 보관함에서 삭제해도 이미 PDF에 찍은 도장은 유지되며 마지막 삭제는 도장 삭제 취소로 되돌립니다.

PDF 두 버전 비교

상단 비교에서 이전 버전과 수정 버전의 PDF를 선택하고 비교 시작을 누릅니다. 선택한 파일의 저장본을 비교하므로 작업 중인 변경을 비교하려면 먼저 다른 이름으로 저장하세요.

왼쪽 변경 목록을 누르면 양쪽 페이지의 해당 위치를 표시합니다. 빨강은 삭제, 초록은 추가, 노랑은 수정입니다. 이전/다음 변경(Alt + ↑/↓), 페이지 쌍 선택, 확대와 스크롤 연동을 지원합니다. 분석 중에는 비교 취소 또는 창 닫기로 중단합니다.

스캔 품질 차이도 화면 변경으로 표시될 수 있고, 내용이 크게 재배치되면 자동 페이지 대응이 부정확할 수 있습니다. OCR·첨부파일·메타데이터·디지털 서명은 비교하지 않습니다. 원본 PDF는 변경하지 않습니다.

처음 시작하기

  1. 시작 메뉴에서 ADF를 실행하면 빈 회색 작업 화면이 열립니다.
  2. PDF 열기를 누르거나 PDF를 창 위로 끌어 놓으세요.
  3. 페이지를 읽고 필요한 작업을 한 뒤 저장하세요. 새 파일을 만들려면 다른 이름 저장을 고르세요.

문서를 닫으면 다시 빈 작업 화면이 나타납니다. 결과는 표준 .pdf 파일이며 다른 PDF 프로그램에서도 열 수 있습니다.

PDF를 더블클릭해서 열려면

Windows 설정 → 앱 → 기본 앱에서 ADF 또는 .pdf를 찾고 ADF를 선택하세요. 한 번 지정하면 이후 PDF를 더블클릭해서 열 수 있습니다.

PDF 우클릭 → 연결 프로그램 → 다른 앱 선택에서도 지정할 수 있습니다. Windows 버전에 따라 표시되는 단계가 다를 수 있습니다.

페이지 정리하기

왼쪽 썸네일에서 Ctrl / Shift로 여러 페이지를 고릅니다. 아래의 왼쪽·오른쪽 회전, 교체, 삭제 버튼으로 정리하세요.

+ 페이지 추가에서는 빈 페이지, 클립보드의 이미지·복사한 파일, PDF·PNG·JPG 파일을 추가합니다. 파일 하나는 바로 넣고 여러 파일은 목록에서 순서를 정합니다. 썸네일 사이에 마우스를 올리면 그 위치에도 +가 나타납니다. 파일이나 페이지를 끌어 놓을 때는 삽입 위치 선을 보고 놓으세요.

오른쪽 위 아이콘으로 한 쪽씩·한 쪽 연속·두 쪽씩·두 쪽 연속·격자 보기를 고릅니다. 아이콘 그룹 사이는 얇은 회색 선으로 구분됩니다. 숫자 1이 그려진 펼침 아이콘은 첫 페이지의 자리이며, 두 쪽 보기에서만 활성화됩니다. 왼쪽 시작은 [1 | 2] → [3 | 4], 오른쪽 시작은 [빈칸 | 1] → [2 | 3]입니다. 실제 페이지 순서는 바뀌지 않습니다. 페이지 번호와 이동 버튼은 미리보기 아래에 있습니다. 한 쪽씩·두 쪽씩 보기에서는 휠로 아래 끝을 넘으면 다음 묶음, 맨 위에서 올리면 이전 묶음으로 이동합니다. 확대하면 먼저 현재 페이지 안에서 스크롤합니다.

Ctrl + Z로 실행을 취소할 수 있습니다.

페이지 번호 넣기·지우기

상단 페이지 번호에서 위치와 형식을 정해 번호를 넣습니다. ADF가 넣은 번호가 있는 페이지에 다시 적용하면 새 설정으로 바꿉니다. 번호 삭제는 ADF가 넣은 번호만 지우며 Ctrl+Z로 되돌릴 수 있습니다. 이전 버전이나 다른 프로그램에서 넣은 번호, 직접 고친 번호, 분할·추출·병합으로 만든 새 PDF의 번호는 지우지 않습니다.

상단 아이콘

첫 줄의 열기·저장·다른 이름 저장·저용량 저장·비교·OCR MD는 아이콘만 표시하고, 마우스를 올리면 이름이 보입니다. 다른 이름 저장은 겹친 디스크, 저용량 저장은 오른쪽 아래에 아래쪽 화살표가 있는 디스크, OCR MD는 눈과 겹친 문서입니다.

둘째 줄 도구는 옅은 구분선으로 묶습니다: 분할·페이지 추출 | 오른쪽·왼쪽 회전 | 페이지 번호·번호 삭제 | 이미지·텍스트 수정·펜·지우개 | 스냅(자석)·캡처·도장 보관함. 창이 좁으면 묶음 단위로 다음 줄에 이어집니다. 펜·지우개·캡처는 한 번 더 누르면 해제됩니다.

펜으로 필기하기

상단 펜 옆의 지우개 버튼에서 4~72pt 크기의 원형 브러시로 필기의 일부만 지웁니다. 원본 PDF의 글·그림·표는 유지합니다. 드래그 중 Esc는 지우기를 취소하고, 완료 후 Ctrl+Z는 한 번의 드래그를 되돌립니다.

상단 펜 버튼은 누를 때마다 켜고 끕니다. 버튼 오른쪽 아래 작은 대각선 화살표로 옵션을 열어 펜슬·마카·브러쉬를 고르고 색상 선택판, 기본 8색, HEX 코드로 색을 선택합니다. 설정창이 열린 상태에서 페이지를 누르면 창만 닫히고 다음 입력부터 필기를 시작합니다. 굵기는 0.2~12.0 pt, 0.2 단위이며 기본값은 검정 펜슬, 1.2 pt입니다. 마카는 반투명하고 브러쉬는 선 끝과 필압에 따라 굵기가 달라집니다. 슬라이더를 움직이면 굵기·색상은 선으로, 지우개 크기는 원으로 즉시 미리보기됩니다. 오른쪽 아래 숫자는 미리보기 배율입니다. 마우스나 Windows 스타일러스로 페이지 위를 드래그하세요. 거의 직선인 선을 그린 뒤 누른 채 약 0.6초 멈추면 직선으로 보정됩니다. 그 뒤 움직이면 같은 방향으로 길이를 조절합니다. 곡선이나 짧은 점은 그대로 유지됩니다.

Esc나 우클릭으로 펜 모드를 끝낸 뒤 필기를 클릭하면 테두리 없이 조절점 8개와 아래쪽 회전 핸들이 나타납니다. 필기를 끌어 이동하고 조절점을 끌어 크기·회전을 바꿉니다. Shift를 누른 회전은 15도 단위입니다. Delete로 선택한 필기를 삭제하며 Ctrl+Z로 그리기·이동·크기·회전·삭제를 취소할 수 있습니다.

그리거나 객체를 조절하는 중 Esc는 진행 중인 조작을 취소합니다. 전체화면에서는 Esc로 전체화면을 해제합니다. 필기는 표준 PDF 잉크 주석과 편집 정보로 저장되어 다시 열어도 객체로 편집하고 인쇄할 수 있습니다. 화면의 조절점은 저장·인쇄되지 않습니다.

편집하고 저장하기

이미 고친 문단은 적용한 글꼴로 계속 편집합니다. 글꼴 대체 창에서 이 문서의 같은 글꼴에 이 선택 적용을 체크하면 같은 원본 글꼴에 대한 선택을 기억합니다. 기본은 체크 해제이며, 다른 글꼴이나 다른 문서는 따로 확인합니다. 기억한 글꼴에 새 글자가 없을 때도 다시 확인합니다.

텍스트를 수정할 때 PDF에 포함된 원본 글꼴을 먼저 사용합니다. PC에 글꼴을 따로 설치하지 않아도 됩니다. 새로 입력한 글자가 내장 글꼴에 없으면 같은 PC 글꼴을 확인하고, 그것도 없을 때만 대체 글꼴로 편집 / 편집 취소를 묻습니다. 취소하면 현재 문단은 그대로 두고 다른 수정 내용은 유지합니다.

텍스트 수정을 누른 뒤 페이지의 글자를 클릭하세요. 줄바꿈으로 이어지는 같은 문단을 함께 선택합니다. 페이지 위에서 바로 내용을 고칩니다. 문단을 선택했을 때만 상단에 글꼴, 크기, 색 도구가 나타납니다. 파란 선택 상자의 테두리를 끌어 옮기거나 오른쪽 아래 손잡이로 크기를 조절하세요.

Enter는 줄바꿈입니다. 빈 곳이나 다른 문단을 클릭하면 수정 내용이 반영됩니다. 완료, Ctrl + Enter, 최종 저장으로도 반영됩니다. 떨어진 열이나 표의 셀은 따로 선택하며, 문서 전체를 자동으로 재배치하지는 않습니다. 텍스트 수정 시 기존 이미지와 선·도형은 유지됩니다.

페이지 번호 위치는 미리보기 가장자리의 아이콘으로 고릅니다. 맞쪽 번호 · 좌우 대칭을 켜면 본문 뷰어의 첫 페이지 시작 위치에 맞춰 두 페이지를 보여 줍니다. 첫 장이나 마지막 장의 반대 칸이 비어 있으면 미리보기에도 그대로 비워 둡니다. 왼쪽 번호는 왼쪽 가장자리, 오른쪽 번호는 오른쪽 가장자리에서 좌우 여백을 적용합니다. 글꼴·크기·색은 한 줄에서 조절하며 색상 코드를 직접 입력할 수 있습니다.

번호 적용 페이지를 비워 두면 전체입니다. 앞에 0 넣기를 켜면 마지막 번호에 맞춰 자릿수를 자동으로 정합니다(예: 001…120). 번호 앞뒤는 없음 · p.1 · 1p 중 고릅니다. 이미지도 페이지 위에서 위치와 크기를 정한 뒤 적용합니다.

텍스트·이미지·페이지 번호와 페이지 작업은 작업 중인 문서에만 적용됩니다. 파일은 저장 전까지 바뀌지 않습니다. 상단 저장 또는 Ctrl+S는 현재 파일에 기록합니다. 오른쪽 다른 이름 저장 또는 Ctrl+Shift+S는 새 경로를 고릅니다. 경로가 없는 새 문서는 먼저 저장 위치를 선택합니다. 필기도 함께 저장됩니다.

저용량 저장에서 목표 용량에 맞춰 품질 자동 조절을 끄면 목표 용량이 회색으로 비활성화됩니다. 켜면 최대 해상도와 JPEG 품질이 비활성화되고 목표 용량을 입력할 수 있습니다.

용량을 줄일 때 이미지만 최적화는 텍스트를 유지합니다. 전체 페이지 이미지 변환을 선택하면 텍스트 검색·복사와 링크·양식이 유지되지 않습니다.

첫 시작과 기능 둘러보기

ADF를 처음 실행하면 실제 상단 버튼 위치를 짚는 6단계 제품 투어가 나타납니다. 열기·저장, 펜·지우개, 선택·캡처, 페이지 정리, 스냅·도장, 비교·OCR를 차례로 안내합니다. 이전·다음으로 이동하고 언제든 건너뛰기나 Esc로 닫으세요. 완료하거나 건너뛰면 다음 실행부터 자동으로 나타나지 않습니다.

다시 보고 싶을 때는 상단 도움말 → 기능 둘러보기를 선택하세요. 버전과 주요 기능을 확인하고 자세한 사용 안내로 이 문서를 열 수 있습니다.

페이지 미리보기 접고 펼치기

왼쪽 페이지 패널의 경계 가운데에 튀어나온 ‹ 버튼을 누르면 패널이 접히고 문서 영역이 넓어집니다. 접힌 상태에서는 왼쪽에 얇은 띠와 › 버튼이 남습니다. 다시 누르면 접기 전 너비로 펼쳐집니다.

펼친 상태에서 경계선을 끌면 패널 너비를 조절할 수 있습니다. 접고 펼쳐도 현재 페이지와 미리보기 스크롤 위치는 유지됩니다. Tab으로 버튼을 선택한 뒤 Space로도 조작할 수 있습니다.

오브젝트 스냅으로 정렬하기

상단 스냅 또는 보기 → 오브젝트 스냅에서 켜고 끕니다. 기본은 켜짐이며 다음 실행에도 설정을 기억합니다.

텍스트 상자를 옮기거나 크기를 조절할 때, 새 이미지를 배치·이동·크기 조절할 때, 도장을 찍을 때 가까운 정렬 위치에 자동으로 맞춰집니다. 같은 페이지의 글·이미지·도형과 페이지 가장자리·중앙이 기준이며 분홍색 점선이 맞춰진 위치를 보여 줍니다. 이미지 비율은 유지합니다.

자유롭게 조절하려면 Alt를 누른 채 움직이세요. 키를 놓으면 스냅이 다시 작동합니다. 안내선은 PDF에 저장되거나 인쇄되지 않습니다.

탐색기에서 바로 병합·분할하기

  1. PDF 한 개를 선택하고 우클릭하면 ADF 아이콘과 함께 ADF로 PDF 분할…이 나타납니다.
  2. PDF 두 개 이상을 선택하고 우클릭하면 ADF 아이콘과 함께 ADF로 PDF 병합…이 나타납니다.
  3. 선택한 파일이 들어 있는 작업 창만 바로 열립니다. 순서나 페이지 범위를 정하고 새 PDF로 저장하세요.

Windows 11의 기본 메뉴에서는 추가 옵션 표시를 누르세요. PDF가 아닌 파일을 함께 선택하면 병합·분할 항목을 표시하지 않습니다. ADF로 열기는 전체 편집기를 실행합니다.

사용안내·라이선스·소스코드 보기

F1 또는 도움말 → 사용안내를 누르세요. 왼쪽 목차에서 기능을 고르거나 검색칸에 단어를 입력하면 제목과 내용을 함께 찾습니다. 사용 안내·라이선스·소스코드는 각각 독립된 창으로 열립니다. 다른 창을 열어도 현재 검색과 읽는 위치를 유지합니다. 창을 열어 둔 채 PDF 작업을 계속할 수 있고 Esc로 닫습니다.

도움말 → 오픈소스 라이선스를 누르면 별도 창에서 구성 요소별 고지와 라이선스 원문을 읽습니다. 도움말 → 소스코드의 독립된 창에서 왼쪽 파일 목차를 선택해 설치된 버전의 소스코드를 앱 안에서 읽습니다. 선택한 소스 저장으로 개별 파일이나 소스 묶음을 원하는 위치에 저장할 수 있습니다. 압축 프로그램을 자동으로 열지 않습니다. 직원에게는 정식 설치 EXE 하나만 전달하면 됩니다. 프로그램·사용안내·라이선스·소스·OCR 모델을 함께 설치하므로 ZIP을 따로 전달하거나 다운로드할 필요가 없습니다.

앱을 열지 않고 읽으려면 시작 메뉴 → ADF → 사용 안내 / 오픈소스 라이선스 / 소스코드를 선택하세요. 사용 안내 창 아래 안내 HTML 열기는 브라우저로 안내를 열어 인쇄할 수 있게 합니다. 모두 인터넷 연결 없이 사용할 수 있습니다.

업데이트와 프로그램 제거

ADF-Setup-0.3.25.exe를 실행하면 기존 버전을 업데이트합니다. 탐색기 메뉴는 새로 연 우클릭 메뉴에서 확인하세요.

프로그램 제거는 Windows 설정 → 앱 → 설치된 앱 → ADF에서 합니다. 개인 PDF 문서는 삭제하지 않습니다.

설치 시 배포 조건 확인

설치의 배포 조건 확인 페이지에서 안내를 읽고 필수 확인란을 체크해야 다음 단계로 넘어갑니다. 확인란은 기본적으로 비어 있습니다.

무단 배포 금지는 각 라이선스가 요구하는 고지·원문·대응 소스 제공 등의 조건을 위반한 배포를 뜻합니다. 오픈소스 라이선스가 허용하는 사용·수정·재배포 권리는 그대로 유지됩니다. 원문과 소스는 앱의 도움말에서 확인하세요. 설치 시 본인 이메일을 수집하지 않습니다.
