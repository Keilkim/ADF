# ADF 0.3.22 펜과 현재 파일 저장

상단 펜 아이콘은 검정·빨강·파랑·초록과 0.2~12.0 pt 굵기를 선택하는 작은 메뉴를 엽니다. 기본은 검정, 1.2 pt이며 슬라이더는 0.2 pt 단위입니다. 펜슬·마카·브러쉬를 제공하며 마카는 반투명, 브러쉬는 끝부분과 태블릿 필압에 따라 굵기를 바꿉니다. 마우스와 Windows 태블릿 이벤트를 처리합니다. PDF 잉크 주석으로 저장하고 인쇄되도록 설정합니다. 필기를 선택하면 외곽선 없이 크기 조절점 8개와 아래쪽 회전 핸들만 나타납니다. 이동·크기·회전·삭제·취소를 지원하며 편집 정보를 PDF에 남겨 다시 열어도 객체로 조절합니다. 한 획 단위 실행 취소·다시 실행, 페이지 밖에서 그리기 중단, Esc 취소, 모드 전환과 전체화면을 지원합니다.

다른 이름 저장 왼쪽에 저장 버튼을 추가했습니다. Ctrl+S는 현재 경로에 원자적으로 저장하고 Ctrl+Shift+S는 별도 경로를 고릅니다. 경로 없는 새 문서는 저장 위치를 묻습니다. 저장 실패 시 원본 파일과 저장되지 않은 편집 상태를 유지합니다.

검증 범위는 마우스와 합성 태블릿 이벤트, 페이지 회전 0·90·180·270도와 CropBox, 저장 후 재열람·렌더링, 점과 페이지 밖 구간, 실행 취소·다시 실행, 굵기와 색, 펜 종류별 저장 모습, 객체 이동·8개 조절점·회전·삭제·조절 중 취소·재열람 후 편집, 읽기 전용 문서, 저장 실패, 기존 기능 회귀 검사입니다. 실물 스타일러스의 드라이버·필기감·지연은 이 환경에서 검증하지 않았습니다. 최종 EXE·설치·소스 일치 검사 결과는 `release/배포상태-0.3.22.md`에 기록합니다. 이전에 Windows Application Control이 차단한 네이티브 검사 실행 파일과 제거 프로그램은 재실행하지 않습니다.
