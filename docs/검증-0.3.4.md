# ADF 0.3.4 검증 기록

2026-09-09, Windows x64 / Python 3.12 / PySide6 6.11.2 / PyMuPDF 1.28.2 / fontTools 4.64.0.

- 전체 소스 테스트: `python -m pytest tests -q` — 119개 및 하위 검사 45개 통과.
- Windows 실제 Qt 플랫폼: `QT_QPA_PLATFORM=windows python -m pytest tests/test_fonts.py tests/test_ui.py -q -k "DocumentFontTests or inline_click_type_ime_font_and_final_save or korean_pdf_font"` — 14개 통과.
- 마지막 CFF 처리 보완 후 글꼴 테스트 12개 재검증 통과.
- 앱 실행 검사: `python main.py --smoke-test .tools/source-smoke-0.3.4.json`. 빈 화면, PDF 렌더링, 내장 한글 글꼴 미리보기·수정·저장, 문단 직접 입력, 최종 일괄 저장, 페이지 번호·추가·회전 검사.
- PC에 없는 자체 테스트 글꼴을 PDF에 포함시킨 테스트를 사용했다. 문자 매핑이 제거된 서브셋, 다른 페이지에만 남은 문자, 삭제된 글리프, CID→GID 변환, 동명 글꼴 충돌을 검사했다. 저장 후 재추출한 글꼴의 글리프 렌더링을 원본과 비교했다.
- 새 글자 미지원 시 원본 PC 글꼴 사용, 대체 허용, 현재 문단 취소 및 다른 변경 보존을 검사했다. 편집 전 원본 PDF는 변경되지 않는다.
- Windows 설치 프로그램과 탐색기 DLL은 컴파일했다. 앞선 0.3.3 실행 검사에서 이 PC의 Windows Application Control이 새 실행 파일·설치 로더·네이티브 테스트 실행을 차단했다. 이 제한이 해소되지 않아 0.3.4 배포 실행 파일·설치·제거 및 네이티브 테스트는 실행하지 않았다. 회사에서 허용한 서명·배포 환경에서 별도 검증이 필요하다. 소스 테스트 통과를 설치 검증 통과로 간주하지 않는다.
- 기존 설치와 기본 PDF 연결, 이전 격리 테스트의 정리 거부된 항목은 변경하지 않았다. macOS 패키지는 이번 Windows 환경에서 만들거나 실행 검증하지 않았다.

재사용 지원 범위는 TrueType·OpenType 및 변환 가능한 비 CID CFF, PDF 표준 글꼴이다. Type3·CID CFF 등 재사용할 수 없는 형식은 동일 PC 글꼴 확인과 대체 선택으로 처리한다. 문단 전체를 대표 글꼴 하나로 편집하는 기존 범위, 가로쓰기와 문단 상자 내 배치 범위를 유지한다.
