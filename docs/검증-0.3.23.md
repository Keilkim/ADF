# ADF 0.3.23 필기 옵션·브러시 지우개·영역 복사

펜 설정창은 네 모서리를 둥글게 처리하고 외곽선을 없앴습니다. 선택 상태는 짙은 회색 배경으로 표시하며 색상판·8색·HEX 입력을 제공합니다. 설정 중 페이지에 마우스나 태블릿을 누르면 해당 입력은 창만 닫고 필기·지우기로 전달되지 않습니다.

원형 지우개는 4~72pt 크기로 PDF 잉크의 일부만 지웁니다. 빠른 드래그의 중간도 처리하며, 진행 중 미리보기·Esc 취소·드래그 단위 실행 취소를 지원합니다. 남은 브러쉬의 굵기와 편집 정보를 보존하며 PDF 본문·이미지·표를 수정하지 않습니다.

영역 복사는 이미지·벡터 그래프·표 선·글자·필기를 함께 이미지로 복사합니다. 선택 표시를 제외한 PDF 렌더링 결과를 사용하며 216dpi, 최대 1,600만 픽셀로 제한합니다. Ctrl+Shift+C와 상단 영역 복사 아이콘을 지원합니다. 표를 편집 가능한 셀로 변환하지는 않습니다.

자동 검증 범위는 마우스·합성 태블릿 입력, 옵션창 밖의 입력 차단, 부분·전체 지우기와 빈 영역, 미리보기·취소·실패 복구, 브러쉬 굵기 보존, 회전 0/90/180/270도 및 CropBox, 저장·재열람·실행 취소·다시 실행, 복사·편집 권한, PDF 원본 내용 보존, 혼합 영역 복사와 도구 전환입니다. 기존 문서 편집·인쇄·도움말·OCR 기능의 회귀 검사도 포함합니다.

정식 릴리즈 검사 결과와 배포 파일은 `release/배포상태-0.3.23.md`에 기록합니다. 설치 후 실행·파일 해시·버전·소스와 EXE 일치·오프라인 리소스를 확인합니다. 설치 검사는 전용 임시 폴더·레지스트리에서 수행합니다. 이전에 Windows Application Control이 차단한 네이티브 검사 실행 파일과 제거 프로그램은 재실행하지 않으며 이 두 항목은 검증 제외로 기록합니다. 실물 스타일러스의 필기감과 외부 앱별 붙여넣기 동작은 별도 확인 대상입니다.
