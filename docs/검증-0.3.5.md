# ADF 0.3.5 검증 기록

2026-09-09, Windows x64 / Python 3.12.

- 전체 소스 검사: `python -m pytest tests -q` — 129개 및 하위 검사 45개 통과.
- 실제 Windows Qt 플랫폼에서 `QT_SCALE_FACTOR=1.5`, `2` 각각 `tests/test_rendering.py` 6개 통과. 패널 폭·썸네일 픽셀 수·버튼 잘림·확대 렌더링·회전 페이지의 잘라낸 영역·스크롤·캐시 메모리를 검사했다.
- 글꼴 검사: `tests/test_fonts.py` 16개 통과. 수정 문단 재선택 및 저장 후 다시 편집, 동명 다른 글꼴 구분, 같은 글꼴 선택 기억, 기본 체크 해제, 취소 및 문서 전환 시 기억 해제를 포함한다.
- 소스 앱 화면을 직접 확인했다. 기본 왼쪽 패널 260px, 세로 PDF 미리보기 폭 약 213px, 버튼 5개와 본문 하단 이동 표시가 맞게 배치된다.
- 기존 Windows Application Control의 실행 제한이 해소되지 않아 배포 실행 파일·설치·제거 및 네이티브 테스트는 실행하지 않았다. 컴파일·소스 검사와 설치 검증을 구분한다. 기존 설치와 기본 PDF 연결은 변경하지 않았다. macOS 패키지는 이 환경에서 검증하지 않았다.
