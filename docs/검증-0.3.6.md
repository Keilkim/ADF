# ADF 0.3.6 검증 기록

2026-09-09, Windows x64 / Python 3.12.

- `python -m pytest tests/test_icons.py tests/test_shell_tools.py -q`: 12개 및 하위 검사 36개 통과. PNG·ICO의 투명 배경과 파란 A, Qt의 작은 아이콘 로드, Windows ICO 디코더와 `DrawIconEx`의 16·20·24·32·40·48·64px 출력 알파, PDF 선택 전달과 병합·분할 창을 검사했다.
- `python main.py --smoke-test .tools/source-smoke-0.3.6.json`: Windows Qt 플랫폼에서 전체 항목 통과. PDF 렌더링, 내장 글꼴 편집·저장, 문단 입력, 페이지 삽입·회전과 마지막 일괄 저장을 확인했다.
- `scripts/build-shell.ps1 -SkipTests`: 네이티브 DLL과 테스트 프로그램 컴파일 성공. 새 네이티브 검사는 DLL 아이콘의 96–384 DPI 렌더링과 실제 메뉴 비트맵을 검사하도록 추가했지만 이 PC에서는 실행하지 않았다.
- Qt 배포 서버의 체크섬 조회가 시간 초과되어, 이전 빌드와 동일한 라이브러리 버전을 확인하고 캐시의 외부 소스 8개를 기존 매니페스트 SHA-256과 대조해 재사용했다. 라이브러리 변경은 없다.
- 기존 Windows Application Control의 실행 제한이 해소되지 않아 배포 실행 파일·설치·제거·탐색기 DLL 실행은 검증하지 않았다. ICO 데이터 파일의 Windows 디코딩 검사는 배포 DLL을 로드하지 않는다. 기존 설치와 기본 PDF 연결은 변경하지 않았다. macOS 패키지는 이 환경에서 검증하지 않았다.
