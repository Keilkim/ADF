XDF PDF → HWPX 변환

파일 → 한글(HWPX)로 변환에서 전체·현재·선택·직접 입력한 페이지를 변환합니다.
저장 전 PDF 수정 내용도 포함합니다. 문단과 표는 편집 가능한 개체로 저장하고,
그림·도형·인식하기 어려운 수식은 이미지로 넣습니다. 글꼴은 맑은 고딕으로
대체합니다. 여백·줄바꿈·개체 배치는 원본과 대조해야 합니다. 한글 앱에서의
실제 표시까지 자동 검증하는 기능은 아직 없습니다.

Gemini AI는 선택한 페이지의 렌더링 이미지와 추출 텍스트를 사용합니다.
PDF 첨부 파일과 음성 녹음을 보내지 않습니다. 변환 창의 전송 항목을 선택한
경우에만 요청합니다. 연결 확인은 모델 접근 권한만 조회하고 문서를 보내지
않습니다. 로컬 추출은 API 없이 처리하며 스캔 문서의 글자는 인식하지 않습니다.
작업은 별도 프로세스에서 실행됩니다. 취소·오류가 발생하면 완성되지 않은
HWPX를 저장하지 않습니다. 취소 전에 Google이 처리한 요청은 과금될 수 있습니다.
같은 이름의 결과는 덮어쓰지 않습니다. 한 작업은 최대 100쪽이며 요청을 자동
재시도하거나 더 비싼 모델로 자동 변경하지 않습니다.

모델 선택 (공식 문서 확인: 2026-10-04)

기본: gemini-3.5-flash-lite. 표준 입력 $0.30 / 출력·추론 $2.50.
한국어 5쪽 PDF의 실제 시험을 69.2초에 완료했고 문단 112개·표 1개·그림 11개를
생성했습니다. 이 변환의 토큰 사용량과 단가로 계산한 추정 비용은 약 $0.073입니다.
한 문서의 시험 결과이며 다른 스캔·복잡한 배치에서 같은 품질을 보장하지 않습니다.

대안: gemini-3.8-flash, thinkingLevel=MEDIUM.
안정 버전, 이미지/PDF 입력과 구조화된 출력을 지원합니다. 대표 페이지의 문단·표
인식은 성공했지만 후속 요청에서 서비스 일시 오류(503)가 반복됐습니다.
2026년 말까지 표준 입력 $0.75 / 출력·추론 $3.75 (각 100만 토큰 기준).
2027년부터 공개 단가는 입력 $1.50 / 출력·추론 $7.50입니다.

복잡한 문서 재시도: gemini-3.1-pro-preview. 입력 200k 이하에서 $2 / $12.
가격은 변경될 수 있고, 실제 사용량은 선택한 경우 conversion.json에 저장합니다.
https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash
https://ai.google.dev/gemini-api/docs/pricing

개발자가 한 번 설정하는 지인 배포용 키

1. Google AI Studio에서 XDF 변환 전용 프로젝트와 Gemini 전용 키를 준비합니다.
   다른 앱에서 쓰는 키는 재사용하지 않는 편이 관리하기 쉽습니다.
2. Spend → Monthly spend cap → Edit spend cap에서 월 지출 한도를 설정합니다.
   프로젝트 지출 한도는 약 10분의 집계 지연 동안 초과 지출이 발생할 수 있습니다.
   알림만 보내는 예산 설정과 실제 지출 한도를 구분하세요.
3. ADF 폴더의 PowerShell에서 다음 명령으로 별도 설정 창을 열고 키를 두 번 입력합니다.

   .\.venv\Scripts\python.exe scripts\configure-hwpx-key.py --gui

   터미널에서 숨겨 입력하려면 --gui를 생략합니다.

   입력은 화면에 표시하지 않으며 명령행 인수·소스·로그에 키를 기록하지 않습니다.
   .tools/hwpx-credentials/credential.enc 및 wrapping.bin이 생성됩니다.
   이 폴더는 Git과 대응 소스 ZIP에 포함하지 않습니다.
4. 개발 실행: .\.venv\Scripts\python.exe main.py
   파일 → 한글(HWPX)로 변환 → 연결 확인을 누릅니다.
5. 공개판은 키를 제외한 기본 빌드로 만듭니다. 지인용 설치 파일은 빌드 후 Inno Setup에
   /DHwpxPrivateBundle=1을 전달하면 release/private에 별도로 생성됩니다. 암호화된
   설정을 HWPX_CREDENTIALS에 설치하며 지인은 키를 입력하거나 표시할 필요가 없습니다.
   Gemini 키를 넣은 설치 파일은 지인에게만 전달하고 공개 릴리즈에는 올리지 마세요.
   설치 파일 없이 배포하는 별도 지인용 폴더 빌드만 XDF_HWPX_BUNDLE_SHARED_KEY=1
   환경 변수를 설정해 ADF.spec이 키를 포함하도록 합니다. 공개 빌드에서는 설정하지 않습니다.

중요한 한계: AES-GCM은 평문 노출과 암호문 손상을 방지합니다. 수신자가 별도
키를 입력하지 않아도 앱을 실행하도록 복호화 재료를 함께 배포하므로, 앱을
분석하거나 실행 중 메모리를 읽는 사람은 Gemini 키를 추출할 수 있습니다.
완전한 키 보호가 필요하면 키를 서버에 두는 중계 구조가 필요합니다.
Google API/IP 제한과 월 지출 한도는 암호화와 별도로 유지해야 합니다.
지인의 공인 IP가 바뀌는 배포 방식에서는 IP 제한이 정상 요청도 차단할 수 있습니다.
https://ai.google.dev/gemini-api/docs/api-key
https://ai.google.dev/gemini-api/docs/billing#project-spend-caps

개발용 대안: GEMINI_API_KEY 또는 XDF_HWPX_API_KEY 환경 변수를 사용할 수 있습니다.
변환 서버 방식은 XDF_HWPX_RELAY_URL 및 XDF_HWPX_SERVICE_TOKEN을 제공하면
표시됩니다. 중계 서버 자체는 이번 지인 배포 방식에 포함되지 않습니다.

검증 범위: 생성한 ZIP·XML 검사와 다시 열기, 문단·표·그림·병합 셀, 페이지 선택,
저장 전 변경 내용, 작업 취소, 기존 결과 보존, 키 암호화·변조 검출을 확인합니다.
실제 Flash-Lite 호출과 5쪽 파일의 ZIP·XML 검증을 완료했습니다. 추출된 원문 글자의
빈도 검사에서 누락은 발견하지 않았지만 글자의 순서·서식까지 동일하다는 의미는
아닙니다. 한글 앱에서 열어 페이지 배치와 표시를 대조하는 검증은 아직 남아 있습니다.
