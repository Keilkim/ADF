# XDF 0.3.44 Windows 검증 기록

검증일: 2026년 10월 6일 (한국시간).

상단 **한글 변환** 버튼에서 PDF → HWPX 변환을 엽니다. 한컴의 한글 기호에 PDF 문서와 변환 화살표를 조합했으며, 기본 크기와 1440px 창에서 버튼의 표시·활성화·24px 아이콘을 확인했습니다.

PDF의 빈 공백 글리프가 `$`로 잘못 추출되는 경우 글 수정 화면을 열기 전에 자동으로 공백으로 복원합니다. 실제 통화 기호는 유지하며, 공백이 없는 부분 글꼴에는 빈 글리프와 폭을 보완합니다. Windows의 진행률 파일 교체가 잠깐 거부돼 HWPX 변환 전체가 실패하는 문제도 수정했습니다.

[릴리즈·다운로드](https://github.com/Keilkim/ADF/releases/tag/v0.3.44) · [공식 홈페이지](https://adf-desktop.vercel.app) · [HWPX 안내](HWPX-변환.txt)

## 재현 및 기능 검사

- 실제 PDF를 만들어 빈 글리프의 잘못된 Unicode 매핑, Unicode 없는 CID 36, 공백 매핑 없는 부분 글꼴을 재현했습니다. 편집 화면의 문자·공백 글리프·폭, 다른 글꼴 선택, 실제 `$100` 유지, 저장·다시 열기·실행 취소·원본 보존을 확인했습니다. 새 공백을 넣은 TrueType·CFF 글꼴의 빈 윤곽과 실제 PDF 간격도 확인했습니다.
- Windows에서 UI가 진행률 파일을 읽어 교체가 거부되는 조건을 재현하고 변환 결과의 편집 가능한 본문·HWPX 저장을 확인했습니다.
- 사용자가 증상을 본 PDF 경로와 선택 글꼴은 제공되지 않아 해당 문서 자체를 검사한 결과는 아닙니다. 실제 달러 윤곽이 있는 글리프는 자동으로 지우지 않습니다.

## 빌드와 설치 검증

- [Windows 빌드·검증](https://github.com/Keilkim/ADF/actions/runs/37425609191): 소스·OCR 검사 **555개**와 세부 검사 **174개** 통과, 환경·선택 의존성에 따른 검사 17개 건너뜀. 탐색기 확장 구성 요소 검사 **13,688개** 통과.
- Windows Server 2022에서 설치·파일 **1,143개** 해시 대조·앱 실행·내장 글꼴 편집·문서 처리·독립 도구·도움말·제거를 확인했습니다.
- 0.3.43 설치 파일에 업데이트 패치를 적용하여 새 파일 목록·문서와 함께 재시작·다른 버전 거부·제거를 확인했습니다. 더 오래된 버전에는 전체 설치 파일을 사용합니다.
- 대응 소스 파일 **733개**, 실행 파일 내부 모듈 **57개**와 리소스 **586개**를 대조했습니다. 외부 라이브러리 소스 아카이브 38개, OCR 모델 5개, 뜻 검색 모델 2개를 포함합니다.
- 빌드 원본 커밋은 `1e4989ecf5b951c6259a2da810466cfbb36ca49e`입니다. [검증된 자산 준비](https://github.com/Keilkim/ADF/actions/runs/37427197784)에서 원본 빌드의 설치 파일·대응 소스·해시를 확인해 초안 릴리즈로 옮긴 뒤 공개합니다.

## 공개판 및 지인용

- 공개 설치 파일과 대응 소스에는 개인 Gemini API 키가 포함되지 않습니다. 빌드된 공개 앱에서 키 없는 Gemini 연결의 거부 및 로컬 HWPX 저장·본문 편집 가능·ZIP/XML 스키마를 확인했습니다. 수정된 모듈과 아이콘이 실행 파일·리소스에 일치하는 것도 대조했습니다.
- 지인용 설치 파일은 로컬에서 따로 만들고 공개 릴리즈·사이트에 업로드하지 않습니다. 격리 설치해 암호화 키 묶음과 Gemini 3.5 Flash-Lite 모델 접근을 확인한 뒤 제거했습니다. 이 연결 검사에서 문서는 전송하지 않았습니다.
- AES-GCM 암호화 파일과 복호화 재료가 함께 포함되므로 지인용 앱의 역분석·메모리 접근에 의한 키 추출을 막지는 못합니다.

## 검증 범위
