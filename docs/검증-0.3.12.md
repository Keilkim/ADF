# ADF 0.3.12 릴리즈 검증

2026-09-09, Windows x64 / Python 3.12.

## 포함 기능

- 첫 실행 기능 소개: 기본 PDF 작업과 ADF의 주요 기능을 한 화면에서 안내한다. 닫으면 이후 자동 표시하지 않으며 도움말 → 기능 둘러보기에서 버전·주요 기능을 다시 확인하고 전체 사용 안내를 열 수 있다.
- 오브젝트 스냅: 텍스트 상자 이동·크기 조절, 새 이미지 배치·이동·크기 조절, 도장 배치를 같은 페이지의 오브젝트와 페이지 가장자리·중앙에 맞춘다. 분홍색 정렬 안내선, 상단 스냅 전환, Alt 임시 해제, 이미지 비율 유지, 회전 페이지 좌표 변환을 포함한다. 안내선은 저장·인쇄하지 않는다.
- 왼쪽 페이지 미리보기: 경계 가운데의 돌출된 ‹ / › 버튼으로 접고 펼친다. 접으면 12px 띠만 남으며 이전 너비, 현재 페이지와 미리보기 스크롤 위치, 배치 중인 이미지를 유지한다. 키보드 Tab·Space로도 조작한다.
- 0.3.11의 도장 보관함, PDF 비교, 손상된 미사용 PDF 객체 처리, 텍스트·이미지·페이지 편집 기능을 함께 포함한다.

## 소스 검증

- 전체 Python 검사: 196개와 하위 검사 96개 통과. 결과: `release/pytest-0.3.12.xml`.
- 소스 앱 `--smoke-test`: 문단 편집·저장, 페이지 번호, 이미지 페이지 추가, 도장 등록·연속 배치·관리·복원, PDF 비교 작업 프로세스에 더해 스냅 이동·크기 조절·Alt 해제·저장·실행 취소와 페이지 패널 접기·키보드 펼치기·너비 복원·미적용 이미지 유지를 확인했다.
- 시작 안내는 별도 임시 설정 파일로 첫 표시·중복 창 방지·닫기·표시 여부 저장·다음 실행에서 생략·도움말로 다시 열기를 검사한다. 사용자 설정에는 기록하지 않는다.
- 네이티브 탐색기 확장 빌드 및 실행: 49,543개 항목 통과. 실제 COM 선택 조합, 사용자 전용 요청 파일 권한, 유니코드 경로 전달과 512개 파일의 단일 프로세스 호출을 검사했다.

## 배포 파일 검증

빌드 후 다음 결과 파일에 성공 여부와 실패·생략 항목을 기록한다. 소스 검증만으로 설치·제거가 검증됐다고 판단하지 않는다.

- `frozen-smoke-0.3.12.json`: 실제 배포 실행파일의 기존 기능과 새 스냅·패널 토글 검사.
- `frozen-worker-smoke-0.3.12.json`, `frozen-tools-smoke-0.3.12.json`: 실행파일의 병합·분할·압축 작업 프로세스와 독립 도구 창 검사.
- `installer-smoke-0.3.12.json`: 별도 임시 폴더와 전용 HKCU 키에서 실제 설치·실행·제거 검사. 기존 ADF 설치와 기본 PDF 연결, 바로가기가 유지되는지도 비교한다.
- `release-audit-0.3.12.json`: 현재 소스와 소스 ZIP, 실행파일 내부 ADF 모듈, 포함 리소스, 외부 소스 및 배포 SHA-256 일치 여부.
- `배포상태-0.3.12.md`: 최종 생성 파일과 검증 결과.

위 배포 결과 파일은 `release` 폴더에 둔다. 이번 릴리즈는 Windows x64용이며 macOS 빌드와 회사 배포용 코드 서명은 수행하지 않는다.
