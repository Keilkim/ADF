# ADF 0.3.21 문의 기능 제거

상단 오른쪽과 전체화면의 문의 메뉴, 문의 창, 메일 앱 호출, 내용 복사와 초안 저장 코드를 제거했습니다. 사용안내의 문의 절과 설치 안내의 문의 주소도 정리했습니다. 설치 시 배포 조건 확인과 도움말의 사용안내·라이선스·소스 열람 기능은 유지합니다.

기존 도움말·전체화면 테스트와 전체 회귀 검사, 소스·실행 파일·설치 후 실행 검사로 연결된 메뉴에 문제가 없는지 확인합니다. 배포 파일과 포함 소스·라이선스·OCR 모델의 일치 여부도 검사합니다. 결과와 실행 범위는 `release/배포상태-0.3.21.md`에 기록합니다. 기존 Windows Application Control이 차단한 네이티브 검사 실행 파일과 제거 프로그램은 재실행하지 않습니다.
