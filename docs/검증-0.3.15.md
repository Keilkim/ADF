# ADF 0.3.15 전체화면 보기

2026-09-09, Windows x64 / Python 3.12.

## 변경 사항

- 여러 장 보기 아이콘 오른쪽에 전체 화면 버튼을 추가했다. F11과 같은 동작이며, 전체화면에서는 해제 아이콘과 설명으로 바뀐다.
- 화면 전체를 PDF 뷰어가 차지한다. 메뉴·도구·페이지 미리보기·페이지 번호·상태 표시줄·열려 있던 도장 보관함과 스크롤 막대는 기본으로 숨긴다.
- 상단·왼쪽·하단 가장자리 12px에서 각각의 도구를 표시한다. 190ms 안에 나타나며, 벗어난 뒤 짧게 기다렸다가 160ms 안에 숨긴다. 애니메이션 중 방향을 바꾸면 현재 위치에서 이어진다. Windows 애니메이션 설정을 따른다.
- 도구는 PDF 위에 겹쳐 표시한다. 나타나거나 숨겨질 때 PDF 뷰어의 크기·배율·페이지 위치를 바꾸지 않는다. 메뉴가 펼쳐졌거나 페이지 번호·검색어를 입력하는 동안에는 관련 도구를 유지한다.
- Esc·F11·문서 더블클릭으로 해제한다. 전체화면에서 이동한 페이지를 유지하면서 원래 창 크기·최대화 상태·미리보기 접힘과 너비·확대 설정을 복원한다. 문서나 앱을 닫을 때도 일반 화면으로 복원한다.

## 검증

- `tests/test_fullscreen.py`: 화면 전체 크기, 도구 숨김, 가장자리별 독립 슬라이드, 애니메이션 반전, PDF 크기 유지, 페이지 번호·미리보기 이동, 펼친 메뉴·검색 입력, Esc·F11·더블클릭 해제, 일반·최대화 창 및 접힌 미리보기·수동 확대·열려 있던 도장 보관함 복원을 검사한다. 테스트 문서 원본은 보존한다.
- 전체 Python 테스트에서 기존 선택·인쇄·추출·편집·도장·비교 기능도 확인한다.
- 앱 `--smoke-test`에 PDF만 보이는 전체화면, 세 방향 도구 표시, 페이지 이동과 Esc 복원 검사를 추가했다. Qt offscreen에서 화면 캡처도 생성한다.

실제 테스트 수와 배포본 정합성, 실행 검증 제한은 `release/배포상태-0.3.15.md`에 기록한다.
