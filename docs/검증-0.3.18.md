# ADF 0.3.18 문의 창과 설치 시 배포 조건 확인

2026-09-09 Windows x64.

- 메뉴 표시줄 맨 오른쪽에 문의 탭을 고정한다. 문서를 열지 않은 상태에서도 사용할 수 있으며, 중복 클릭은 기존 문의 창을 다시 보여준다. Esc와 앱 닫기로 문의 창을 닫는다.
- 받는 주소는 draftup@naver.com으로 고정한다. 본인 이메일, 제목, 문의 내용을 필수 입력한다. 본인 이메일은 회신 주소로 쓰며 설정이나 설치 정보에 저장하지 않는다.
- 기본 메일 앱에서 확인 후 보내는 방식을 사용한다. ADF 자체가 메일을 전송하거나 PDF를 자동 첨부하지 않는다. 메일 앱을 못 열면 내용을 복사하거나 .eml 초안을 저장할 수 있다. 긴 문의는 URL로 잘리지 않도록 초안 저장을 안내한다.
- 메일 URL의 받는 사람과 쿼리를 사용자 입력으로 바꿀 수 없도록 구성한다. 저장하는 초안은 Reply-To와 제목·본문을 보존하며 수신자를 추가하거나 현재 PDF를 첨부하지 않는다. 완전히 작성한 초안만 파일로 저장한다.
- 설치의 배포 조건 페이지에서 기본적으로 비어 있는 확인란을 체크해야 다음 버튼이 활성화된다. 뒤로 갔다가 체크를 해제하면 다시 비활성화한다. 설치 직전에도 확인 상태를 검사한다.
- 무인 설치도 기본적으로 거절한다. 배포 담당자가 안내를 확인하고 해당 버전의 `/ADFACKNOTICE=0.3.18`을 명시한 경우에만 진행한다. 대화형 설치의 확인란은 이 옵션을 주어도 자동으로 체크되지 않는다.

무단 배포 금지의 범위는 **라이선스 조건을 위반한 배포**이다. ADF와 포함 라이브러리의 오픈소스 라이선스가 부여한 재배포·수정 권리를 전면 금지하거나 별도 승인을 요구하는 조건을 추가하지 않는다. [GNU 라이선스 FAQ](https://www.gnu.org/licenses/gpl-faq.en.html).

자동 테스트는 이메일 누락·잘못된 주소·제목과 본문 누락, 수신자 변경과 헤더 삽입 방지, 한글 및 긴 내용 보존, 초안의 회신 주소, 메일 앱 부재, 우측 탭 위치와 문의 창 생명주기를 검사한다. 실제 메일 앱 호출은 테스트에서 대체하여 외부 전송을 하지 않는다. 설치 검사는 동일한 설치 파일로 미확인 상태의 무인 설치 거절과 명시적 확인 후 설치·실행을 확인한다. 제거 프로그램이 Windows Application Control에 차단된 경우에는 그 실행을 성공으로 기록하지 않으며, 명시적인 검사 옵션으로 해당 실행을 생략하고 검사에서 만든 GUID 경로·등록 정보만 정리한다. 실행한 검사 결과와 배포 해시는 `release/배포상태-0.3.18.md`에 기록한다.
