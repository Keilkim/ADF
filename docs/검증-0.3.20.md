# ADF 0.3.20 소스 열람과 Markdown 이미지 저장

2026-09-09 Windows x64.

- 직원에게 전달하는 정식 설치 EXE 하나에 실행 구성 요소·사용안내·라이선스·소스·OCR 모델을 포함한다. 소스코드는 앱 안의 파일 목차에서 읽고, 개별 파일이나 원본 소스 묶음을 원하는 위치에 저장한다. 저장 중 취소는 기존 대상 파일을 보존한다. 시작 메뉴의 도움말 바로가기도 앱의 해당 창을 연다.
- OCR의 이미지 저장은 MD 안에 Base64 포함이 기본이다. 그림·그래프·표 원본·확인용 페이지를 모두 선택한 방식으로 저장한다. 분리 방식은 PNG와 상대경로를 사용한다.
- 결과 폴더와 MD 이름은 날짜_문서이름_고유ID이며, 이미지에는 같은 접두사와 페이지·영역 번호를 붙인다. 고유 ID는 내보내기 창마다 새로 생성하고 미리 보기에 표시한다. 공백·한글·괄호·%·#이 있는 이름도 상대 링크를 인코딩해 연결한다. 파일 분리 시 결과 폴더 전체를 옮겨야 한다.
- Base64는 전체 문서를 메모리에 모으지 않고 이미지 단위로 나누어 기록한다. 변환은 취소 가능한 작업 프로세스에서 수행하고, 완료된 폴더만 한 번에 저장 위치에 반영한다. 기존 결과를 덮어쓰지 않는다.
- 일부 Markdown 뷰어는 data URI 이미지를 제한한다. 이 경우 분리 저장을 선택하도록 설정 창과 결과 안내에 표시한다. 호환성 참고: [GitHub Markup의 Base64 이미지 이슈](https://github.com/github/markup/issues/270).

검증은 실제 한글 OCR, 두 이미지 방식의 PNG 바이트 일치, 분리 폴더 이동 후 이미지 연결, 고유 이름, 잘못된 파일 이름, 처리 중 취소, 소스 읽기·원본 저장·저장 취소를 포함한다. 최종 실행·설치·해시 검사 결과는 `release/배포상태-0.3.20.md`에 기록한다. 기존 Windows Application Control에서 차단한 네이티브 검사 실행 파일과 제거 프로그램은 재실행하지 않는다.
