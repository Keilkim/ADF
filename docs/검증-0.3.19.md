# ADF 0.3.19 메뉴·도움말 창·밝은 테마 정리

2026-09-09 Windows x64.

- 문의는 맨 오른쪽 상단에서 다른 메뉴와 같은 높이·모양·반응을 사용한다. 전체 화면의 상단 메뉴에서도 문의를 열 수 있다.
- 도움말의 사용 안내·오픈소스 라이선스·소스코드 순서를 창 제목과 일치시켰다. 각 항목은 독립된 창으로 열며, 같은 항목을 다시 누르면 해당 창을 앞으로 가져온다. 다른 창의 검색·목차 위치를 바꾸지 않는다. Esc는 해당 창만 닫고 앱 종료는 열린 안내 창을 모두 닫는다.
- 도구 모음의 중복 도움말 버튼과 선택 도구 목록을 제거했다. 보기 메뉴에서 선택·손 도구를 전환한다. 기본 텍스트 선택, 글자 위 I자 커서와 이미지 클릭 선택은 유지한다.
- Qt 팔레트를 명시적으로 밝게 지정해 시스템의 어두운 팔레트가 입력칸·목차·탭 배경에 섞이지 않게 했다. 버튼·선택 표시·입력 포커스·진행 표시·문서 선택 표시를 무채색으로 맞췄다. 전체 화면도 기존의 밝은 문서 배경을 유지한다.
- 사용자 문서의 글자·그림 색상, 오류 및 비교 결과의 의미 있는 색상은 변경하지 않는다. 문의의 본인 이메일 필수 입력, 로컬 초안 저장과 설치 시 배포 조건 확인을 유지한다.

검증은 독립 창의 내용·검색 보존·닫기 동작, 문의 메뉴의 실제 클릭과 상단 정렬, 선택·손 도구 전환 후 텍스트·이미지 선택, 전체 화면 복귀를 포함한다. 어두운 시스템 팔레트 조건에서도 밝은 창이 렌더링되는지 확인한다. 전체 회귀 테스트와 소스/실행 파일 스모크 검사, 설치 결과·소스·리소스 일치 검사 결과는 `release/배포상태-0.3.19.md`에 기록한다. 이전 검사에서 Windows Application Control이 차단한 제거 프로그램과 네이티브 검사 실행은 생략하며, 별도 GUID 경로의 검사 파일·등록 정보만 정리한다.
