# ADF 0.3.13 변경 및 검증

2026-09-09, Windows x64 / Python 3.12.

## 변경 사항

- 인쇄 대상을 전체·현재 페이지·왼쪽 선택 페이지·직접 입력 중에서 선택한다. 쉼표와 범위를 함께 입력하고 잘못된 범위는 인쇄 전에 표시한다.
- 용지에 맞춤·큰 페이지만 축소·실제 크기·배율 지정을 제공한다. 프린터에서 선택한 용지와 방향을 유지하며 인쇄 가능 영역을 기준으로 비율을 유지해 가운데 배치한다.
- 페이지 번호 입력칸이 문서의 페이지 수와 글꼴에 맞춰 넓어진다.
- 왼쪽 미리보기는 하단 5개 버튼의 폭(204px)을 유지한다. 패널을 넓히면 여백과 스크롤 영역을 포함해 온전히 들어가는 열만 추가한다. 기존 400px 상한을 제거하고 본문 최소 폭을 확보한다.
- 상단·파일 메뉴·페이지 우클릭에서 선택 페이지 추출을 실행한다. 왼쪽 선택을 전달하고 파일명·저장 위치를 지정한다. 기존 분할창에도 왼쪽 선택을 전달한다.

## 검증 범위

- 전체 Python 테스트: 206개 및 하위 검사 108개 통과. 인쇄·추출 검사는 `tests/test_printing.py`, 반응형 열 배치와 다중 선택·순서 변경·접기 복원은 `tests/test_rendering.py`에 포함한다.
- 비연속 페이지의 실제 색상, 현재 페이지, 역순 선택 인쇄를 PDF 출력으로 확인했다.
- 세로·가로 A3 원본을 A4 용지에 맞추고 비대칭 여백 안에 배치하는지, 실제 크기와 지정 배율이 유지되는지 확인했다.
- 1~5열의 경계 너비와 수평 잘림 방지, 3~5자리 번호 표시를 확인했다.
- 실제 작업 프로세스를 통한 추출에서 저장 전 회전·선택 순서·텍스트·암호를 확인했다. 원본 보존, 권한 제한, 기존 출력 파일 보존도 검사한다.
- 실행파일 `--smoke-test`에 비연속·현재 페이지 인쇄, A4 맞춤, 5열 배치, 번호칸 너비, 선택 추출 검사를 추가했다.

빌드·실행·설치 결과는 `release/frozen-smoke-0.3.13.json`, `frozen-worker-smoke-0.3.13.json`, `installer-smoke-0.3.13.json`, `release-audit-0.3.13.json`에 기록한다. 실제 종이 출력은 검사하지 않았다.
