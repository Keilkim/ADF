# XDF 0.3.43 Windows 검증 기록

검증일: 2026년 10월 4일 (한국시간).

**파일 → 한글(HWPX)로 변환**에서 PDF의 문단·병합 표·그림을 HWPX 문서로 저장합니다. 로컬 추출과 Gemini AI를 선택할 수 있으며 저장 전 수정 내용도 포함합니다. 온라인 전송은 사용자가 선택한 경우에만 실행합니다.

[릴리즈·다운로드](https://github.com/Keilkim/ADF/releases/tag/v0.3.43) · [공식 홈페이지](https://adf-desktop.vercel.app) · [HWPX 안내](HWPX-변환.txt)

## 공개 배포 파일

- 공개 Windows 설치 파일은 개인 Gemini API 키를 포함하지 않습니다. API 연결이 없는 공개판은 로컬 추출로 사용할 수 있습니다.
- 지인용 설치 파일은 로컬에서 따로 만들었고 공개 릴리즈·사이트에는 업로드하지 않았습니다. AES-GCM 암호화 파일과 복호화 재료가 함께 포함되므로 역분석·메모리 접근에 의한 키 추출을 막지는 못합니다.
- 새 의존성의 대응 소스 추가로 변경량이 패치 기준을 초과하여 이번에는 전체 설치 파일만 제공합니다.
- Windows 파일은 미서명입니다. macOS는 기존 서명·공증 완료 [0.3.30](https://github.com/Keilkim/ADF/releases/tag/v0.3.30)을 유지합니다.

## 빌드·기능 검증

- [Windows 빌드·검증](https://github.com/Keilkim/ADF/actions/runs/37203850482): 소스 검사 548개와 세부 검사 170개 통과, 환경·선택 의존성에 따른 검사 17개 건너뜀. 탐색기 확장 구성 요소 검사 13,688개 통과.
- Windows Server 2022에서 설치·파일 1,139개 해시 대조·도움말 바로가기·앱 실행·문서 처리·독립 도구 창·제거를 확인했습니다.
- 대응 소스 파일 729개, 실행 파일 내부 모듈 57개와 리소스 582개를 대조했습니다. 외부 라이브러리 대응 소스 아카이브 38개와 로컬 OCR 모델 5개, 뜻 검색 모델 2개를 포함합니다.
- 빌드 원본 커밋은 `eb6fe93f649855701ee910cc6263a0c7cf460910`입니다. [검증된 자산 준비](https://github.com/Keilkim/ADF/actions/runs/37204902054)에서 빌드 결과와 대응 소스의 해시를 확인해 초안 릴리즈로 옮겼습니다.
- 이 PC의 빌드 실행 파일로 HWPX 작업자를 실행하고 편집 가능한 본문·ZIP·XML·스키마를 확인했습니다. 공개 빌드에 암호화 키 묶음이 없는 것도 검사했습니다.
- 지인용 설치 파일을 격리 설치해 암호화 키 묶음과 Gemini 모델 접근을 확인한 뒤 제거했습니다. 이 연결 검사는 문서를 전송하지 않습니다.

## 실제 문서 변환

한국어 가로형 PDF 5쪽을 Gemini 3.5 Flash-Lite로 변환했습니다. API 작업 시간은 약 69.2초였고, 결과에는 문단 112개·표 1개·그림 11개가 포함됐습니다. HWPX ZIP·XML·스키마와 5개 구역의 재읽기를 확인했습니다. 원본 PDF와 변환 결과는 공개 저장소에 포함하지 않았습니다.

입력 토큰 30,835개와 출력 토큰 25,542개를 사용했습니다. 당시 공개된 유료 단가를 적용한 계산값은 약 0.073달러이며 실제 청구액을 확인한 결과는 아닙니다. 글자 빈도 대조에서 누락 신호는 없었지만 문장의 정확성·순서·배치를 보장하는 검사는 아닙니다.

## 검증 제한

- 한컴 한글에서 실제 표시를 대조하는 검증은 완료하지 않았습니다. 글꼴은 맑은 고딕으로 대체하며 원본의 줄바꿈·여백·복잡한 다단 배치는 달라질 수 있습니다.
- Windows Server의 탐색기 메뉴 조합 검사는 기존과 동일하게 실패했습니다. Windows 10/11의 실제 탐색기 통합과 입력 장치 전체 검증이 완료됐다는 의미는 아닙니다.
- 이 PC의 일반 Windows 화면을 사용하는 전체 앱 검사는 기존 도장 카드의 마우스 이동 후 버튼 표시 검사에서 실패했습니다. HWPX 작업자·설치 파일 데이터 대조·격리 제거·지인용 API 연결 검사는 통과했습니다. 서버의 화면 없는 실행 검사는 통과했습니다. 이 PC의 화면 없는 재실행에서는 OCR 진행 단계 표시 검사도 실패했으므로 로컬 전체 화면 검사는 별도 확인이 필요합니다.
