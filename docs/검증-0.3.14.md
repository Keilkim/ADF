# ADF 0.3.14 변경 및 검증

2026-09-09, Windows x64 / Python 3.12.

## 변경 사항

- 오른쪽 문서 화면은 선택 도구로 시작한다. 텍스트는 드래그하고 이미지는 클릭해서 선택한다. 손 도구는 상단에서 선택한다.
- 텍스트 위에 마우스를 올리면 I 모양 커서를 표시한다. 이미지와 빈 곳에서는 화살표를 유지한다. 회전된 페이지와 OCR 텍스트에도 적용한다.
- 이미지 클릭 선택에서 Ctrl+C로 원본 이미지와 투명도를 복사한다. 복사 권한을 확인하며 기존 이미지 삭제·실행 취소를 지원한다.
- 텍스트 드래그는 배경 이미지가 있어도 텍스트를 선택한다. 빈 곳 클릭·Esc·페이지 이동·도구 전환은 이전 선택을 해제한다.
- 텍스트 선택 중 Delete가 페이지 전체를 삭제하지 않도록 한다. 페이지 삭제는 왼쪽 목록에서 페이지를 선택해서 실행한다.
- 0.3.13의 인쇄 범위·현재 페이지·맞춤 배율·번호칸 너비·반응형 미리보기·페이지 추출 수정을 포함한다.

## 검증 범위

- `tests/test_ui.py`: 기본 텍스트 선택·복사, 이미지 선택·투명도 복사·삭제·실행 취소, OCR 배경 위 텍스트 드래그, 회전된 페이지 선택, 페이지 이동 후 선택 해제, 읽기 전용 PDF의 복사 권한, 텍스트·이미지·손 도구의 호버 커서를 검사한다.
- `adf/release_checks.py`: 앱 통합 검사에서 기본 선택 도구와 텍스트 호버 커서, 텍스트 드래그를 확인하고 기존 인쇄·추출·도장·비교·정렬 기능을 함께 검사한다.
- 마우스 이동에 따른 텍스트 판정은 페이지별 좌표를 캐시한다. 편집 후 문서 리비전이 바뀌면 다시 읽으며 최대 16개 페이지를 보관한다.

실행 결과와 테스트 수, 패키지 검증 및 제한은 `release/배포상태-0.3.14.md`에 기록한다. 앱 통합 검사의 화면 입력은 실제 사용자 마우스와 충돌하지 않도록 Qt offscreen 환경에서 수행한다. 실제 종이 출력은 검사하지 않는다.
