# ADF 0.3.8 검증 기록

2026-09-09, Windows x64 / Python 3.12.

- 변경 영역의 기존 UI 검사 2개 통과: 보기 모드별 시작 위치 활성/비활성 및 비활성 버튼 클릭 차단, 두 쪽 보기 전환, 한 페이지 휠 이동, 저용량 저장의 수동/자동 입력 상태 전환, 작업 프로세스를 통한 검색 가능한 PDF 저장을 확인했다.
- Windows Qt 소스 화면에서 1100px 폭의 보기 그룹 구분선과 비활성 시작 위치 버튼, 저용량 저장의 수동/자동 상태를 확인했다. 비활성 입력칸과 라벨이 회색으로 표시된다.
- 네이티브 탐색기 확장과 테스트 프로그램을 `scripts/build-shell.ps1 -SkipTests`로 컴파일했다. 이번 변경은 보기 및 압축 설정 UI이며 압축 알고리즘은 변경하지 않았다.
- 기존 Windows Application Control 제한이 해소되지 않아 설치·제거·배포 EXE 및 탐색기 확장의 실제 실행은 검증하지 않았다. 소스 실행/컴파일과 배포 실행 검증을 구분한다. 기존 설치와 PDF 기본 연결은 변경하지 않았다.
