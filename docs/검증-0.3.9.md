# ADF 0.3.9 검증 기록

2026-09-09, Windows x64.

- 기존 보기 UI 검사 1개 통과: 한 쪽씩·연속·전체 보기에서 시작 위치 버튼 클릭 차단, 두 쪽 보기에서 활성화, 페이지 이동과 회전 기능을 확인했다.
- Windows Qt 소스 화면에서 두 쪽 보기의 원래 아이콘과 단일 보기의 옅은 아이콘을 비교했다. 선택·비선택 두 비활성 상태의 픽셀 색이 `#C4CBD5`인지 확인했다. 운영체제의 자동 회색 변환에 의존하지 않고 비활성 그림을 직접 제공한다.
- 기존 Windows Application Control 제한으로 배포 EXE·설치·탐색기 확장의 실제 실행은 검증하지 않았다. 소스 화면 확인과 배포 실행 검증을 구분한다. 기존 설치와 PDF 기본 연결은 변경하지 않았다.
