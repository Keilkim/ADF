# 필기와 영역 복사 개선

2026-09-10 · ADF 0.3.23에 포함된 변경입니다.

- 펜 설정은 네 모서리가 둥근 창으로 표시합니다. 외곽선 없이 회색 선택 배경을 사용하며, 펜슬·마카·브러쉬를 바로 고릅니다.
- 색상 선택판은 316 × 150px이며 색상 슬라이더, 기본 8색, HEX 코드 입력을 제공합니다. 펜 굵기는 0.2~12pt입니다.
- **필기 → 지우개**에서 4~72pt 크기의 원형 브러시로 필기의 일부만 지웁니다. 원본 PDF의 글·그림·표는 유지합니다. 드래그 중 결과를 미리 보여주며, 마우스를 놓으면 한 번의 편집으로 반영합니다. Ctrl+Z로 전체 드래그를 되돌리고 Esc로 진행 중인 지우기를 취소합니다. 필기와 지우개 크기는 각각 기억합니다.
- 설정창이 열린 동안 페이지를 누르거나 문질러도 해당 동작은 창만 닫습니다. 다음 입력부터 필기·지우기가 시작됩니다. 마우스와 태블릿에 적용합니다.
- 상단 **영역 복사** 아이콘 또는 **편집 → 영역 복사**를 누르고 드래그하면 선택 영역의 글·그림·그래프·표·필기를 함께 이미지로 복사합니다. 다른 앱에서 Ctrl+V로 붙여넣습니다. 현재 페이지 안의 영역을 복사하며 Esc로 도구를 종료합니다.
- 기본 선택 도구에서는 Ctrl+C로 텍스트를 복사하고 **Ctrl+Shift+C**로 같은 선택 영역을 이미지로 복사합니다. 텍스트가 없는 영역은 Ctrl+C로도 이미지 복사가 가능합니다. 영역을 아직 선택하지 않았다면 Ctrl+Shift+C가 영역 복사 도구를 켭니다.

이미지 복사는 PDF를 216dpi로 렌더링하며 큰 영역은 1,600만 픽셀로 제한합니다. 화면의 선택 표시나 도구 UI는 복사하지 않습니다. 표 모양을 유지하는 이미지 복사이며, 엑셀의 편집 가능한 셀로 변환하는 기능은 포함하지 않습니다. 문서의 복사·편집 권한과 잠긴 필기를 존중합니다.

검증: 마우스·합성 태블릿 입력, 창을 닫는 입력의 전달 차단, 지우기 미리보기·취소·실패 복구·빈 영역·부분/전체 삭제, 필압 브러쉬 모양 유지, 0/90/180/270도 회전과 CropBox, 저장 후 재열람, 실행 취소·다시 실행, PDF 원본 내용 보존, 권한 제한, 혼합 영역의 복사 결과, 도구 전환과 창 너비별 배치를 확인합니다. 실물 스타일러스와 외부 앱별 붙여넣기 동작은 별도 확인이 필요합니다.
