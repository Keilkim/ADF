ADF 오픈소스 라이선스

ADF는 오픈소스 구성 요소를 사용합니다. 아래 원문과 소스 파일은 프로그램과 함께 설치되며 인터넷 없이 확인할 수 있습니다. 앱의 도움말 → 오픈소스 라이선스에서는 모든 구성 요소의 원문을 검색해서 읽을 수 있습니다.

프로그램의 라이선스

새로 작성한 ADF 코드와 탐색기 확장 코드는 GNU AGPL v3 이상으로 제공합니다. 해당 조건에 따라 사용·수정·재배포할 수 있으며 보증 없이 제공됩니다. 사용자가 제공한 명세와 외부 구성 요소에는 각 권리자의 조건이 적용됩니다.

소스코드와 다시 빌드하기

직원에게는 정식 설치 EXE 하나만 전달하세요. 소스 묶음도 안에 포함되어 함께 설치됩니다. 앱의 도움말 → 소스코드에서 압축 프로그램 없이 읽고 원본을 저장할 수 있습니다.

SOURCES 폴더에는 현재 버전의 ADF-Source ZIP, ADF-ThirdParty-Sources ZIP과 SHA256SUMS.txt가 들어 있습니다. ADF 소스 ZIP의 README에 빌드 방법이 있으며 외부 소스에는 해당 프로젝트의 빌드 문서가 들어 있습니다.

배포할 때는 안내·고지·소스가 포함된 정식 설치 파일을 전달하세요. 설치된 ADF.exe 하나만 따로 복사하면 실행에 필요한 파일이 빠집니다. 이 안내가 모든 배포 형태에 대한 법률 검토를 대신하지는 않습니다.
